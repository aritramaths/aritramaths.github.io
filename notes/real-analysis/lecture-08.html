Density, Cluster Points, and Upper and Lower Limits

Read this lecture online, then continue to the next chapter. Figures and exercises are being adapted separately for the web edition.

A Familiar Statement That Deserves a Proof

Motivation 8.1

You have probably heard since childhood that between any two different real numbers there is a rational number. Perhaps you have also heard the same statement about irrational numbers. We have used this picture of a crowded number line many times. But why is it true, even when the two numbers are extremely close together?

Today let us prove those familiar statements formally. We shall begin with the three descriptions of density from the end of Lecture [lec:7]. They say the same thing in three different languages: small windows, approximating sequences, and open intervals. Learning to pass from one language to another will make the proofs much easier to discover.

Three Ways to Say That a Set Is Dense

Recall the three equivalent views of density. For a set \(S\subseteq\mathbb{R}\), they are:

  1. For every \(x\in\mathbb{R}\) and every \(\varepsilon>0\), some \(s\in S\) satisfies \(|x-s|<\varepsilon\).

  2. Every \(x\in\mathbb{R}\) is the limit of a sequence whose terms belong to \(S\).

  3. Every nonempty open interval \((a,b)\) contains a point of \(S\).

The first description lets you choose a target and an accuracy. The second asks for a whole list of increasingly accurate approximations. The third says that the set leaves no open gap in the real line. Let us check every implication carefully.

Show proof

Proof. From (1) to (2). Fix the number \(x\) we want to approximate. Apply (1) with \(\varepsilon=1\) to choose \(s_1\in S\) with \(|s_1-x|<1\); apply it with \(\varepsilon=1/2\) to choose \(s_2\), and continue. For each \(n\), we choose \(s_n\in S\) so that \[|s_n-x|<\frac1n.\] These choices produce a sequence. To verify its limit, let \(\varepsilon>0\) and choose an integer \(N>1/\varepsilon\). For every \(n\ge N\), \[|s_n-x|<\frac1n\le\frac1N<\varepsilon.\] Thus \(s_n\to x\). The sequence need not be monotone, and the selected values need not be different: neither is required by the definition of a limit.

From (2) to (3). Let \(a<b\). We need a point of \(S\) strictly between these two numbers. Choose the midpoint \[x=\frac{a+b}{2}, \qquad \delta=\frac{b-a}{2}>0.\] By (2), there is a sequence \((s_n)\) in \(S\) with \(s_n\to x\). Eventually \(|s_n-x|<\delta\), which means \[a=x-\delta<s_n<x+\delta=b.\] Any one term after that stage is the point of \(S\) that we need. The strict error bound keeps it away from both endpoints.

From (3) to (1). Fix \(x\in\mathbb{R}\) and \(\varepsilon>0\). The interval \((x-\varepsilon,x+\varepsilon)\) is nonempty because its length is \(2\varepsilon>0\). By (3), it contains some \(s\in S\). This is exactly \(|x-s|<\varepsilon\), proving (1). ◻

Remark 8.1

Density does not say that every point of \(\mathbb{R}\) belongs to \(S\). It says that points of \(S\) can be found as close as we wish to every real target. An approximating sequence can have its limit outside the set containing all its terms.

A Rational Number Between Any Two Real Numbers

Theorem 8.1

Density of the Rationals

The set \(\mathbb{Q}\) is dense in \(\mathbb{R}\). Equivalently, if \(a,b\in\mathbb{R}\) and \(a<b\), there is a rational number \(q\) with \(a<q<b\).

Show proof

Proof. We want a fraction \(m/n\) inside \((a,b)\). If we fix the denominator \(n\), the possible fractions form a grid \[\ldots,\frac{-2}{n},\frac{-1}{n},0,\frac1n,\frac2n,\ldots\] whose neighbouring points are \(1/n\) apart. Our idea is to choose this spacing smaller than the interval’s length, then take the first grid point strictly to the right of \(a\).

By the Archimedean property, choose \(n\in\mathbb{N}\) such that \[n>\frac1{b-a}.\] Since \(b-a>0\), multiplication gives \(n(b-a)>1\), or equivalently \(na+1<nb\).

Let \[m=\lfloor na\rfloor+1.\] Here \(\lfloor t\rfloor\) denotes the greatest integer at most \(t\), so \(\lfloor t\rfloor\le t<\lfloor t\rfloor+1\). Therefore \[na<m=\lfloor na\rfloor+1\le na+1<nb.\] The first inequality is strict even if \(na\) itself is an integer: we have chosen the next integer. The floor inequalities also hold for negative numbers, so the argument requires no assumption that \(a\) or \(b\) is positive.

Divide by the positive integer \(n\): \[a<\frac mn<b.\] Since \(m\in\mathbb{Z}\) and \(n\in\mathbb{N}\), the number \(m/n\) is rational. This proves the interval description of density, and hence all three descriptions. ◻

An Irrational Number Between Any Two Real Numbers

Theorem 8.2

Density of the Irrationals

The set \(\mathbb{R}\setminus\mathbb{Q}\) is dense in \(\mathbb{R}\). Thus every nonempty open interval contains an irrational number as well as a rational number.

Show proof

Proof. Let \(a<b\). We know how to find a rational number in any open interval. To obtain an irrational number, we shall add the fixed irrational number \(\sqrt2\) to a rational one. We must choose the rational number in the right place so that the sum lands inside \((a,b)\).

Because \(a-\sqrt2<b-\sqrt2\), rational density supplies a rational \(q\) with \[a-\sqrt2<q<b-\sqrt2.\] Adding \(\sqrt2\) gives \[a<q+\sqrt2<b.\] The number \(q+\sqrt2\) is irrational. Indeed, if it were rational, subtracting the rational number \(q\) would show that \(\sqrt2\) is rational, contradicting Lecture [lec:1]. Thus \((a,b)\) contains an irrational number. ◻

There is another useful way to carry out the same idea, with a very small irrational displacement. Choose a positive rational \(r\) with \(r\sqrt2<b-a\), then choose a rational \(q\) in \((a,b-r\sqrt2)\). We get \(a<q+r\sqrt2<b\). This sum is irrational, since otherwise subtracting \(q\) and dividing by the nonzero rational \(r\) would make \(\sqrt2\) rational. Both versions use the same ingredients: rational density and one known irrational number.

Approximating One Kind of Number by the Other

Theorem 8.3

Rational and Irrational Approximations to Every Real Number

For every \(x\in\mathbb{R}\), there is a sequence of rational numbers converging to \(x\), and there is a sequence of irrational numbers converging to \(x\).

Show proof

Proof. For each \(n\in\mathbb{N}\), apply rational density to \((x,x+1/n)\) and choose \(q_n\in\mathbb{Q}\) in that interval. Then \[0<q_n-x<\frac1n,\] so \(q_n\to x\) by the definition of convergence. Apply irrational density to the same interval and choose \(r_n\in\mathbb{R}\setminus\mathbb{Q}\) there. The estimate \(0<r_n-x<1/n\) similarly proves \(r_n\to x\). ◻

Example 8.1

Irrational terms approaching a rational target

Let \(q\in\mathbb{Q}\). An explicit irrational approximation sequence is \[r_n=q+\frac{\sqrt2}{n}.\]

Show worked solution

If one term \(r_n\) were rational, then \(\sqrt2=n(r_n-q)\) would be rational. Thus every term is irrational. Nevertheless, \[|r_n-q|=\frac{\sqrt2}{n}\longrightarrow0.\] For a given \(\varepsilon>0\), any integer \(N>\sqrt2/\varepsilon\) works for every \(n\ge N\). So irrational terms can converge to a rational limit; irrationality is not preserved on taking limits.

Example 8.2

Rational terms approaching an irrational target

Let \(\alpha\in\mathbb{R}\setminus\mathbb{Q}\). Define \[q_n=\frac{\lfloor n\alpha\rfloor}{n}.\] Then every \(q_n\) is rational, and \(q_n\to\alpha\).

Show worked solution

The numerator is an integer and the denominator is a positive integer, so \(q_n\in\mathbb{Q}\). The floor inequalities give \[\lfloor n\alpha\rfloor\le n\alpha<\lfloor n\alpha\rfloor+1.\] After division by \(n>0\), \[q_n\le\alpha<q_n+\frac1n.\] Equality \(q_n=\alpha\) is impossible because \(\alpha\) is irrational. Consequently \(0<\alpha-q_n<1/n\), and the definition of convergence gives \(q_n\to\alpha\). This also works for negative irrational targets. The selected rational values need not all be distinct; the estimate, rather than distinctness, proves the limit.

Warning 8.1

The nature of each term and the nature of the limit are separate questions. A sequence of rational numbers can converge to an irrational number, and a sequence of irrational numbers can converge to a rational number. Density is precisely what makes these approximation processes possible.

A Set Forgets Repetitions; a Sequence Remembers Them

Before we discuss upper and lower limits, let us settle a question that can easily cause confusion. If I give you a sequence, can you simply collect its values into a set and find the limit points of that set? Would those automatically be the limit points of the sequence?

Consider the simplest possible example: \[x_1=x_2=x_3=\cdots=5.\] As a set of values, this is just \(\{5\}\). A set does not record that the same value appeared once, ten times, or at every index. But the sequence does record those appearances. The difference matters.

What a limit point of a set asks for

Recall the definition of an accumulation point of a set. The number \(L\) is an accumulation point, or limit point, of \(A\subseteq\mathbb{R}\) when \[\forall\varepsilon>0\quad \exists a\in A:\quad 0<|a-L|<\varepsilon.\] The inequality \(0<|a-L|\) says that \(a\) must be a point different from \(L\). We puncture the neighbourhood by removing its centre. This is the meaning of a limit point of a set throughout these notes.

For \(A=\{5\}\), there is no other point to find. Thus \(5\) is an isolated point of this set. If \(L\ne5\), the window of radius \(|L-5|/2\) around \(L\) misses \(A\) altogether. The set therefore has no accumulation points at all. The fact that \(5\) itself belongs to every neighbourhood of \(5\) does not meet the requirement: the definition asks for another point.

What a limit point of a sequence asks for

For a sequence, we instead ask whether we can find terms close to \(L\) arbitrarily far along the list. The value may repeat. It is the indices that must continue farther and farther.

Definition 8.1

Cluster Point or Subsequential Limit of a Sequence

A real number \(L\) is a cluster point, also called a limit point or subsequential limit, of a real sequence \((x_n)\) if \[\forall\varepsilon>0\quad \forall N\in\mathbb{N}\quad \exists n\ge N:\quad |x_n-L|<\varepsilon.\]

Notice that the error is allowed to be zero. We have not required \(x_n\ne L\). A term equal to \(L\) is certainly close to \(L\). However, one early occurrence is not enough: after every proposed starting index \(N\), another suitable index must still be available.

Theorem 8.4

Three Ways to Recognise a Sequence Cluster Point

For a real sequence \((x_n)\) and \(L\in\mathbb{R}\), the following are equivalent:

  1. \(L\) satisfies the cluster-point definition above.

  2. For every \(\varepsilon>0\), infinitely many indices \(n\) satisfy \(|x_n-L|<\varepsilon\).

  3. There are indices \(n_1<n_2<\cdots\) such that \(x_{n_k}\to L\).

The values at those indices need not be distinct.

Show proof

Proof. First fix \(\varepsilon>0\). If only finitely many suitable indices existed, we could choose \(N\) larger than all of them. Then no \(n\ge N\) would give the required error, contradicting (1). Conversely, infinitely many positive integer indices cannot all be smaller than one fixed \(N\). Thus (2) supplies a suitable \(n\ge N\) for every \(N\), proving (1).

Now assume (1). Choose \(n_1\ge1\) with \(|x_{n_1}-L|<1\). Having chosen \(n_k\), apply (1) with \[N=n_k+1,\qquad \varepsilon=\frac1{k+1}\] to choose \(n_{k+1}>n_k\) with \(|x_{n_{k+1}}-L|<1/(k+1)\). This produces a subsequence satisfying \[|x_{n_k}-L|<\frac1k\qquad(k\in\mathbb{N}).\] Given any \(\varepsilon>0\), choose \(K>1/\varepsilon\). For \(k\ge K\) the last error is less than \(1/K<\varepsilon\), so \(x_{n_k}\to L\).

Finally, suppose \(x_{n_k}\to L\). Given \(\varepsilon>0\), choose \(K\) so that \(k\ge K\) gives \(|x_{n_k}-L|<\varepsilon\). Given any original index \(N\), choose \(k\ge\max\{K,N\}\). Because \(n_k\ge k\), the index \(n=n_k\) is at least \(N\) and has the required error. This proves (1). ◻

The constant sequence: one set point, infinitely many appearances

Return to \(x_n=5\). For every \(\varepsilon>0\) and every \(N\), choose \(n=N\). Then \[|x_n-5|=0<\varepsilon.\] Thus \(5\) is a cluster point of the sequence. In fact the entire sequence converges to \(5\). The range set \(\{5\}\) has no accumulation points. Both conclusions are correct: they answer different questions.

[Figure being adapted for the online edition.]

Alternation: two isolated set points, two sequence cluster points

Now let \(x_n=(-1)^n\). Its range set is \[A=\{-1,1\}.\] Each of these points is isolated. A window of radius \(1/2\) around \(1\) contains no point of \(A\) other than \(1\), and the same is true around \(-1\). A real number outside \(A\) has positive distance from both points, so a sufficiently small window around it misses \(A\) altogether. Consequently this finite set has no accumulation points.

The sequence tells a different story. The even subsequence is \(x_{2k}=1\) for every \(k\), and the odd subsequence is \(x_{2k-1}=-1\) for every \(k\). Hence \(1\) and \(-1\) are both cluster points of the sequence. There are no others: if \(L\notin\{-1,1\}\), choose \[\varepsilon=\frac12\min\{|L-1|,|L+1|\}>0.\] Every term of the sequence stays outside that window around \(L\). Thus the cluster-point set of the sequence is exactly \(\{-1,1\}\).

Warning 8.2

The assertion \(x_n\to L\) and the assertion that \(L\) is a limit point of the sequence are different statements. Convergence controls every sufficiently late term. A cluster point controls a suitably selected subsequence. The alternating sequence has two cluster points and no limit. A convergent sequence has exactly one real cluster point, namely its limit, because every subsequence has that same limit.

What information disappears when we form the range?

The sequence \[5,0,0,0,0,\ldots\] has range \(\{0,5\}\), but its only sequence cluster point is \(0\). The value \(5\) occurs only once; no late tail returns to it. The value \(0\) occurs at every index after the first.

For \(x_n=1/n\), the values are all distinct. Its range has the set accumulation point \(0\), and the sequence also has the cluster point \(0\). For \(x_n=n\), the range \(\mathbb{N}\) has no finite set accumulation point, and the sequence has no real cluster point either: every bounded window is eventually left behind.

There is a useful exact description. If \(A=\{x_n:n\in\mathbb{N}\}\) and \(A'\) denotes the accumulation-point set of \(A\), then \[\boxed{\begin{gathered} \{\text{real cluster points of }(x_n)\}\\ =A'\cup\{a\in A:a\text{ occurs infinitely often in }(x_n)\}. \end{gathered}}\] Here is why. If \(a\) occurs at infinitely many indices, a constant subsequence gives the cluster point \(a\). If \(L\in A'\), every neighbourhood of \(L\) contains infinitely many distinct points of \(A\): if it contained only finitely many other points, a smaller radius than all their positive distances from \(L\) would exclude them all. Only finitely many values appear before any fixed index \(N\). Therefore some point in the neighbourhood must appear at an index \(n\ge N\), which proves that \(L\) is a sequence cluster point.

Conversely, suppose \(L\) is a sequence cluster point but occurs only finitely often, possibly not at all. If \(L\notin A'\), some radius \(\delta>0\) gives no point of \(A\) in the punctured window \(0<|a-L|<\delta\). If \(L\) occurs, choose \(N\) after its last occurrence; otherwise take \(N=1\). There would then be no \(n\ge N\) with \(|x_n-L|<\delta\), contradicting the sequence cluster-point condition. Hence \(L\in A'\).

This explains both classroom examples at once. For the constant and alternating sequences, the range contributes no set accumulation points. Their sequence cluster points come from values that keep appearing. When we study \(\limsup\) and \(\liminf\), it is the persistent behaviour of the sequence tails that matters.

If Every Selected Journey Has the Same Destination

Intuition 8.1

Let us return to our train. The whole sequence is the train, and selecting some of its entries, in their original order, is our way of watching some of its coaches. If every possible selection settles at the same destination \(L\), then the whole sequence must settle there as well.

Suppose instead that, however far along the list we go, there is still another entry outside one fixed window around \(L\). We can choose one such entry, then another farther along, then another. We have selected an entire subsequence that keeps missing that window. So it cannot be true that every selected journey approaches \(L\). Let us write this selection carefully.

Theorem 8.5

Testing Convergence by Subsequences

Let \((x_n)\) be a real sequence and let \(L\in\mathbb{R}\). The following statements are equivalent:

  1. \(x_n\to L\).

  2. Every subsequence of \((x_n)\) converges to \(L\).

  3. Every subsequence of \((x_n)\) has a further subsequence converging to \(L\).

If \((x_n)\) is bounded, these are also equivalent to:

  1. Every convergent subsequence of \((x_n)\) has limit \(L\).

Show proof

Proof. The subsequence theorem proves \((1)\Rightarrow(2)\). Statement (2) implies (3), since a subsequence is one of its own further subsequences. Also, (2) immediately implies (1): the original sequence is the subsequence obtained by choosing \(n_k=k\). We need not exclude that choice.

The useful selection argument is \((3)\Rightarrow(1)\). Suppose \(x_n\) does not converge to \(L\). Negating the definition supplies \(\varepsilon_0>0\) such that \[\forall N\in\mathbb{N}\quad\exists n\ge N:\quad |x_n-L|\ge\varepsilon_0.\] Choose one such \(n_1\). After choosing \(n_k\), use \(N=n_k+1\) to choose \(n_{k+1}>n_k\). Then \[|x_{n_k}-L|\ge\varepsilon_0\qquad(k\in\mathbb{N}).\] Every term of this selected sequence stays outside the same open window. Every further subsequence does so too, so none can converge to \(L\). This contradicts (3), proving (1).

Now suppose \((x_n)\) is bounded. Statement (1) implies (4) by the subsequence theorem. If (1) fails, construct the bad subsequence above. It is bounded, so Bolzano–Weierstrass supplies a convergent further subsequence. By (4), its limit is \(L\), contradicting its fixed distance of at least \(\varepsilon_0\) from \(L\). This proves the last equivalence. ◻

Warning 8.3

Every subsequence converges to \(L\) and every convergent subsequence has limit \(L\) make different claims. The second statement does not forbid terms from escaping to infinity. For example, \[x_{2k}=0,\qquad x_{2k-1}=k\qquad(k\ge1).\] Its only finite subsequential limit is \(0\), but the full sequence does not converge. Any convergent subsequence is bounded, so it contains only finitely many of the odd-indexed terms \(k\). Its remaining terms are zero. Thus boundedness is essential in statement (4).

Upper and Lower Limits

Upper and Lower Limits

A bounded sequence may fail to converge while still having well-defined upper and lower long-term behaviour. For \(a_n=(-1)^n\), the two persistent levels are \(-1\) and \(1\). For \(a_n=5\), there is one persistent level, namely \(5\). We want quantities that record these extremes while ignoring any finite beginning.

A huge first term may be the largest term of the whole sequence, but it need not describe what happens far along the list. So we examine tails.

Definition 8.2

Limsup and Liminf of a Bounded Sequence

For a bounded real sequence \((a_n)\), put \[u_N=\sup\{a_n:n\ge N\},\qquad \ell_N=\inf\{a_n:n\ge N\}.\] Define the upper and lower limits by \[\limsupn a_n=\lim_{N\to\infty}u_N,\qquad \liminfn a_n=\lim_{N\to\infty}\ell_N.\] They are called the limsup and liminf, respectively.

To check that these limits exist, choose \(m,M\) with \(m\le a_n\le M\) for every \(n\). Every tail is nonempty and bounded. Removing a tail’s first entry cannot enlarge its supremum or decrease its infimum, so \[m\le\ell_N\le\ell_{N+1}\le u_{N+1}\le u_N\le M.\] Thus \((\ell_N)\) increases and is bounded above, while \((u_N)\) decreases and is bounded below. Monotone convergence gives both limits. In particular \(\liminf a_n\le\limsup a_n\). A tail supremum or infimum need not be attained.

Example 8.3

One Level and Two Levels

Find the upper and lower limits of \(a_n=5\) and \(b_n=(-1)^n\).

Show worked solution

For the constant sequence, every tail contains only entries equal to \(5\). Thus \(\ell_N=u_N=5\) and \[\liminf a_n=\limsup a_n=5.\] The sequence has subsequential limit \(5\), but its range \(\{5\}\) has no accumulation point as a set: no different point is available in a punctured neighbourhood.

For \(b_n=(-1)^n\), every tail contains both \(-1\) and \(1\). Hence \[\ell_N=-1,\qquad u_N=1,\qquad \liminf b_n=-1,\quad\limsup b_n=1.\] Its even and odd subsequences are constantly \(1\) and \(-1\). These are limit points of the sequence. Its finite range \(\{-1,1\}\) has no accumulation point as a set. Replacing the list by its range erases the infinitely repeated visits.

Example 8.4

Working with the Tail, Not the First Few Terms

Find the limsup and liminf of \[a_n=(-1)^n+\frac1n,\qquad b_n=2+\frac{(-1)^n}{n}.\]

Show worked solution

The even terms \(a_{2k}=1+1/(2k)\) tend to \(1\), while the odd terms \(a_{2k-1}=-1+1/(2k-1)\) tend to \(-1\). Let \(e_N\) be the first even index at least \(N\). Every odd term is at most \(0\), while the even terms are greater than \(1\) and decrease. Therefore \[u_N=1+\frac1{e_N}\longrightarrow1.\] Every term exceeds \(-1\), and every tail contains odd terms arbitrarily close to \(-1\). Consequently \(\ell_N=-1\), although no term equals \(-1\). Thus \[\boxed{\limsup a_n=1,\qquad\liminf a_n=-1.}\] For \(b_n\), every \(n\ge N\) satisfies \[2-\frac1N\le b_n\le2+\frac1N.\] The tail infimum and supremum lie between the same outer bounds, so \[\boxed{\limsup b_n=\liminf b_n=2.}\] The terms alternate around \(2\), but the size of that alternation tends to zero. Alternating sides does not itself prevent convergence.

Example 8.5

The Beginning May Be Misleading

Let \(a_1=100\), \(a_2=-50\), and \(a_n=1+1/n\) for \(n\ge3\). Find its limsup and liminf.

Show worked solution

The whole sequence has maximum \(100\) and minimum \(-50\). Those values include the beginning. For \(N\ge3\), the tail is \(1+1/N,1+1/(N+1),\ldots\), so \[u_N=1+\frac1N,\qquad\ell_N=1.\] Hence both limiting bounds equal \(1\). The two early outliers affect only the first few tail bounds, not the limits of those bounds.

Example 8.6

Three Persistent Levels

For \(k\ge1\), put \[a_{3k-2}=0,\qquad a_{3k-1}=2+\frac1k,\qquad a_{3k}=5-\frac1k.\] Find its subsequential limits, liminf, and limsup.

Show worked solution

The three displayed subsequences tend to \(0\), \(2\), and \(5\). There are no other subsequential limits. Any convergent subsequence uses at least one of the three kinds of indices infinitely often. Otherwise it would have only finitely many entries. Selecting those indices gives a further subsequence tending to \(0\), \(2\), or \(5\), and the subsequence theorem forces the original selected sequence to have that same limit.

Every tail contains a zero, and all terms are nonnegative, so \(\ell_N=0\). All terms are below \(5\), and \(5-1/k\) approaches \(5\) within every tail, so \(u_N=5\). Thus \[\boxed{\liminf a_n=0,\qquad\limsup a_n=5.}\] The middle value \(2\) is also a cluster value. Liminf and limsup record the extreme cluster values, without claiming there are only two.

Subsequential Limits and the Tail Envelopes

Theorem 8.6

Largest and Smallest Cluster Values

For a bounded real sequence, its limsup is its largest subsequential limit and its liminf is its smallest subsequential limit.

Show proof

Proof. Write \(L=\liminf a_n\) and \(U=\limsup a_n\). Suppose \(a_{n_k}\to c\). For each fixed \(N\), the selected indices eventually exceed \(N\), so \(\ell_N\le a_{n_k}\le u_N\) for all sufficiently large \(k\). Order preservation gives \(\ell_N\le c\le u_N\). Letting \(N\to\infty\) yields \(L\le c\le U\).

We must show the endpoints are actually reached. For \(U\), start with \(n_0=0\). Having chosen \(n_{k-1}\), choose \[N_k\ge\max\{n_{k-1}+1,k\},\qquad u_{N_k}<U+\frac1k.\] Such an index exists since \(u_N\to U\). The approximation property of the supremum supplies \(n_k\ge N_k\) with \(a_{n_k}>u_{N_k}-1/k\). Since the tail suprema decrease to \(U\), we have \(u_{N_k}\ge U\). Consequently \[U-\frac1k<a_{n_k}\le u_{N_k}<U+\frac1k.\] Also \(n_k>n_{k-1}\), so we have a subsequence converging to \(U\).

For \(L\), begin with \(m_0=0\). Choose \(M_k\ge\max\{m_{k-1}+1,k\}\) with \(\ell_{M_k}>L-1/k\). The approximation property of the infimum supplies \(m_k\ge M_k\) with \(a_{m_k}<\ell_{M_k}+1/k\). Since \(\ell_{M_k}\le L\), \[L-\frac1k<\ell_{M_k}\le a_{m_k}<L+\frac1k.\] Thus \(m_k>m_{k-1}\) and \(a_{m_k}\to L\). Both extreme cluster values have now been constructed. ◻

Theorem 8.7

The Envelope Criterion for Convergence

A bounded real sequence converges to \(L\) if and only if its liminf and limsup are both equal to \(L\).

Show proof

Proof. Suppose \(a_n\to L\). Given \(\varepsilon>0\), all sufficiently late entries lie between \(L-\varepsilon\) and \(L+\varepsilon\). Every later tail has \[L-\varepsilon\le\ell_N\le u_N\le L+\varepsilon.\] The limits of the two bounds lie between the same outer numbers for every \(\varepsilon>0\). Both must therefore equal \(L\).

Conversely, suppose liminf and limsup both equal \(L\). Every convergent subsequence has its limit between the smallest and largest cluster values, now both \(L\). So every convergent subsequence goes to \(L\). The sequence is bounded; the subsequence test gives \(a_n\to L\). This is precisely our train intuition: no other destination remains available to any convergent selection.

We can see the same trapping directly. Given \(\varepsilon>0\), choose \(N_1,N_2\) so that \(\ell_n>L-\varepsilon\) for \(n\ge N_1\) and \(u_n<L+\varepsilon\) for \(n\ge N_2\). For every \(n\ge\max\{N_1,N_2\}\), \[L-\varepsilon<\ell_n\le a_n\le u_n<L+\varepsilon.\] This is \(|a_n-L|<\varepsilon\). There is no room left for different long-term behaviour. ◻

Intuition 8.2

Liminf and limsup describe the lowest and highest destinations that selected parts of a bounded sequence can approach. If these coincide, every possible convergent selection shares that destination. If the whole sequence kept missing it, we could select those misbehaving entries and, by boundedness, select again to obtain a convergent journey elsewhere. The two equal boundary values rule that out.

Infinite Limits and Extended Envelopes

The same tail language can record escape to infinity. We say \(a_n\to+\infty\) when every real bound is eventually exceeded. This is not convergence to an additional real number. The notation \(\overline\mathbb{R}=\mathbb{R}\cup\{-\infty,+\infty\}\) permits upper and lower limits of unbounded sequences, using extended tail suprema and infima.

For \(a_{2k}=0\) and \(a_{2k-1}=k\), every tail has infimum \(0\) and is unbounded above: its liminf is \(0\) and its limsup is \(+\infty\). For \(a_n=(-1)^n n\), every tail is unbounded in both directions: the liminf and limsup are \(-\infty\) and \(+\infty\). An unbounded sequence need not tend to either infinity. The expressions \(\infty-\infty\) and \(0\cdot\infty\) are not defined arithmetic operations; each competing-growth limit must be studied from its terms.

Why Density Will Matter in Functional Equations

Motivation 8.2

Suppose we know a function at every rational input. Those inputs are dense: we can approach any real number through rational numbers. Can we therefore recover the function at every real input?

The approximation of the inputs is only part of the argument. We also need a condition that controls the outputs when the inputs are close. In our later study of continuity, this will become a useful method for turning information on a dense set into information on the whole line.

Here is a preview through an additive functional equation. Suppose \(f:\mathbb{R}\to\mathbb{R}\) satisfies \[f(x+y)=f(x)+f(y)\qquad(x,y\in\mathbb{R}).\] Write \(c=f(1)\). First \(f(0)=0\) and \(f(-x)=-f(x)\). Repeated addition gives \(f(m)=mc\) for every integer \(m\). If \(q=m/n\) with \(n\ge1\), then \[n f(m/n)=f(m)=mc,\qquad f(q)=cq.\] Thus the equation already determines the function on \(\mathbb{Q}\).

Now suppose we additionally know the following condition: whenever \(t_n\to0\), we have \(f(t_n)\to0\). This is a condition about the function’s behaviour near \(0\); it will be explained through continuity when we study that topic later. For a fixed real \(x\), choose rational numbers \(q_n\to x\) using density. Then \(x-q_n\to0\), so \[f(x)-cq_n=f(x)-f(q_n)=f(x-q_n)\longrightarrow0.\] Since \(cq_n\to cx\), the left side tends to \(f(x)-cx\). Therefore \(f(x)-cx=0\), and \(f(x)=cx\) for every real \(x\).

This is how density does real work in a functional equation: first solve on rational inputs, then use a condition that allows their approximation to carry information to every real input. Density alone does not impose that condition on an arbitrary function. Appendix B offers further density problems.
