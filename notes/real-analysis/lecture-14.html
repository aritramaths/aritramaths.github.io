Continuity and Density

Read this lecture online, then continue to the next chapter. Figures and exercises are being adapted separately for the web edition.

The Nearby Height and the Actual Height

Motivation 14.1

In a limit problem we stand near an input \(c\) and ask where the outputs are heading. The value at \(c\) itself does not enter that question. Continuity asks us to compare the answer with one more piece of information: the actual height \(f(c)\). Do the nearby outputs approach the height already assigned at the point?

For example, \((x^2-9)/(x-3)\) approaches \(6\) as \(x\to3\), but its formula does not assign any value at \(3\). Assign the value \(6\) and the nearby behaviour fits the point. Assign the value \(10\) and the nearby behaviour is unchanged, but it no longer fits the assigned height.

The familiar picture of a curve with no break is useful for a first impression. The definition below tells us exactly what to check, including for functions whose graphs cannot be represented by a single smooth curve.

Definition 14.1

Continuity at a point

Let \(A\subseteq\mathbb{R}\), let \(f:A\to\mathbb{R}\), and let \(c\in A\). We say that \(f\) is continuous at \(c\) if \[\forall\varepsilon>0\quad\exists\delta>0\quad \forall x\in A:\qquad |x-c|<\delta\ \Longrightarrow\ |f(x)-f(c)|<\varepsilon.\] The function is continuous on \(A\) if it is continuous at every point of \(A\).

Choose an output window around the actual value \(f(c)\). We must find an input window around \(c\) whose domain points all map into that output window. Unlike the limit definition, the continuity definition allows \(x=c\). This causes no difficulty: at that input the error is \(|f(c)-f(c)|=0\). The radius may depend on \(c\). What if one radius had to work at every point? That is the question of Appendix C.

[Figure being adapted for the online edition.]

At \(c=1\), the chosen point is \((1,1)\). For \(\varepsilon=1/2\), the choice \(\delta=1/6\) works: every point of the blue curve above the orange input window stays inside the blue output window. The point at \(x=1\) is included.

Remark 14.1

Only inputs in \(A\) are tested. If \(c\) is an isolated point of \(A\), choose \(\delta>0\) so that the only domain point in \((c-\delta,c+\delta)\) is \(c\) itself. Every function \(f:A\to\mathbb{R}\) is continuous at that isolated point. We therefore define continuity directly, without requiring that \(c\) be an accumulation point of the domain.

Continuity Written as a Limit

Theorem 14.1

The limit must equal the assigned value

Let \(c\in A\) be an accumulation point of \(A\), and let \(f:A\to\mathbb{R}\). Then \[f\text{ is continuous at }c \quad\Longleftrightarrow\quad \lim_{\substack{x\to c\\x\in A}}f(x)=f(c).\] Equivalently, writing \(h=x-c\), we have \[\lim_{\substack{h\to0\\c+h\in A}} \bigl(f(c+h)-f(c)\bigr)=0.\]

Show proof

Proof. If \(f\) is continuous, its radius for \(\varepsilon\) also works for the deleted condition \(0<|x-c|<\delta\). This gives the displayed limit. Conversely, suppose the limit equals \(f(c)\). The limit definition provides a radius controlling every admissible \(x\ne c\). At \(x=c\), the output error is zero, so the same radius proves continuity.

Finally, \(|h|=|x-c|\), and the output error in the last display is exactly \(|f(x)-f(c)|\). Changing the input from \(x\) to \(h=x-c\) does not change the condition we are testing. ◻

Thus a small change in input must produce a small change in output, at the point under discussion. We do not require the two changes to have the same size. The radius \(\delta\) may depend on the chosen tolerance \(\varepsilon\) and on the point \(c\).

Example 14.1

A direct proof for a linear function

Prove that \(f(x)=mx+b\) is continuous at every real \(c\), for fixed real numbers \(m,b\).

Explanation 14.1

For any input \(x\), \[|f(x)-f(c)| =|mx+b-(mc+b)|=|m|\,|x-c|.\] If \(m\ne0\), choose \(\delta=\varepsilon/|m|\). Then \(|x-c|<\delta\) makes the output error less than \(\varepsilon\). If \(m=0\), the function is constant and its output error is always zero; any positive radius works. The point \(c\) was arbitrary.

Example 14.2

A direct proof for the square function

Prove directly that \(f(x)=x^2\) is continuous at every real \(c\).

Explanation 14.2

Factor the output error: \[|x^2-c^2|=|x-c|\,|x+c|.\] We control the moving second factor by first requiring \(|x-c|<1\). Then the triangle inequality gives \[|x+c|=|(x-c)+2c|\le |x-c|+2|c|<1+2|c|.\] For a prescribed \(\varepsilon>0\), choose \[\delta=\min\left\{1,\frac{\varepsilon}{\,2|c|+1\,}\right\}.\] If \(|x-c|<\delta\), both restrictions hold and \[|x^2-c^2| \le |x-c|\,(2|c|+1)<\varepsilon.\] The same choice also works at \(x=c\), where the error is zero. This proves continuity at the arbitrary point \(c\).

Connecting Continuity with the Two Sides

Theorem 14.2

The left height, the right height, and the point

Suppose that \(c\in A\) and that \(A\) has points arbitrarily close to \(c\) on both sides. Then \(f:A\to\mathbb{R}\) is continuous at \(c\) exactly when \[\lim_{x\to c^-}f(x)=f(c)=\lim_{x\to c^+}f(x),\] where the limits use inputs from \(A\).

Show proof

Proof. By the two-sided limit criterion, the full limit equals \(f(c)\) if and only if both one-sided limits equal \(f(c)\). The preceding theorem says that this is exactly continuity. ◻

Three numbers must fit together: the height approached from the left, the height approached from the right, and the actual height at the point. Agreement of the two side limits alone is not sufficient if the assigned value is different.

At the left endpoint \(a\) of an interval \([a,b]\), with \(a<b\), there are no interval inputs to the left. Continuity relative to this domain means \(\lim_{x\to a^+}f(x)=f(a)\). At the right endpoint it means \(\lim_{x\to b^-}f(x)=f(b)\). We do not ask the function to have values outside its domain.

Example 14.3

An endpoint has only the available side

Is \(f(x)=\sqrt{x}\) continuous at \(0\) on its domain \([0,\infty)\)?

Explanation 14.3

Yes. Given \(\varepsilon>0\), take \(\delta=\varepsilon^2\). For every domain input with \(|x-0|<\delta\), we have \(0\le x<\varepsilon^2\), so \[|f(x)-f(0)|=\sqrt{x}<\varepsilon.\] This proves continuity at the endpoint. It is also a direct proof of the right-hand limit \(\sqrt{x}\to0\) as \(x\to0^+\).

Passing a Sequence Limit through the Function

Motivation 14.2

Suppose inputs \(x_1,x_2,\ldots\) approach \(c\). If the function is continuous there, eventually those inputs enter any sufficiently small input window, and their outputs enter the requested window around \(f(c)\). In this sense continuity lets us take the limit inside: \[\lim_{n\to\infty}f(x_n) =f\!\left(\lim_{n\to\infty}x_n\right).\] The right side means \(f(c)\), so the function must be defined and continuous at \(c\). Merely having a limit somewhere else is not enough.

Theorem 14.3

The sequential criterion for continuity

Let \(f:A\to\mathbb{R}\) and \(c\in A\). The following are equivalent:

  1. \(f\) is continuous at \(c\).

  2. For every sequence \((x_n)\) in \(A\) with \(x_n\to c\), we have \(f(x_n)\to f(c)\).

The input sequence is allowed to contain \(c\), or even to be constantly equal to \(c\).

Show proof

Proof. Assume (i), and choose any sequence in \(A\) tending to \(c\). Given \(\varepsilon>0\), continuity provides \(\delta>0\) such that \(|x-c|<\delta\) implies \(|f(x)-f(c)|<\varepsilon\) for \(x\in A\). Since \(x_n\to c\), there is \(N\) such that \(n\ge N\) implies \(|x_n-c|<\delta\). Thus \(n\ge N\) also implies \(|f(x_n)-f(c)|<\varepsilon\). This is (ii).

For the converse, suppose that \(f\) is not continuous at \(c\). Negating the definition gives a fixed \(\varepsilon_0>0\) such that, for every \(\delta>0\), there is a point \(x\in A\) with \[|x-c|<\delta,\qquad |f(x)-f(c)|\ge\varepsilon_0.\] For each \(n\), use \(\delta=1/n\) and choose such a point \(x_n\). Then \(|x_n-c|<1/n\), so \(x_n\to c\), but every output remains at least \(\varepsilon_0\) from \(f(c)\). Hence \(f(x_n)\) does not tend to \(f(c)\), contrary to (ii). Therefore \(f\) is continuous. ◻

Warning 14.1

One successful input sequence cannot prove continuity. The criterion requires the conclusion for every domain sequence tending to the point. To disprove continuity, one sequence for which the conclusion fails is enough. Density will soon give us particularly useful sequences to test.

Assigning the Value at a Missing Point

Example 14.4

The sine quotient can be completed continuously

For a real number \(A\), define \[S_A(x)= \begin{cases} \dfrac{\sin x}{x},&x\ne0,\\[3pt] A,&x=0. \end{cases}\] For which \(A\) is \(S_A\) continuous at zero?

Explanation 14.4

The standard sine limit gives \[\lim_{x\to0}S_A(x)=1\] for every \(A\): changing one value does not change that deleted limit. Continuity requires the limit to equal \(S_A(0)=A\). It therefore holds exactly when \(A=1\).

We can also see the failure for \(A\ne1\) with the sequential criterion: choose \(x_n=1/n\). Then \(x_n\to0\) and \(S_A(x_n)\to1\ne A=S_A(0)\).

Example 14.5

Oscillation can coexist with continuity

Compare the behaviour at zero of \[U(x)=\sin(1/x)\quad(x\ne0)\] and the function \[V(x)= \begin{cases} x\sin(1/x),&x\ne0,\\ 0,&x=0. \end{cases}\]

Explanation 14.5

For \(U\), the inputs \[x_n=\frac1{2\pi n+\pi/2},\qquad y_n=\frac1{2\pi n+3\pi/2}\] both approach zero, but \(U(x_n)=1\) and \(U(y_n)=-1\). Thus the deleted limit does not exist. No assigned value at zero can make this function continuous there.

For \(V\), every nonzero input satisfies \[|V(x)-V(0)|=|x\sin(1/x)|\le |x|.\] Given \(\varepsilon>0\), the choice \(\delta=\varepsilon\) proves continuity at zero directly, including the input \(x=0\). The sine still oscillates, but the factor \(x\) makes the entire output fit into every window around zero. The size of the oscillation matters as much as the oscillation itself.

Density Meets Continuity

Motivation 14.3

In the density lecture we promised to return to a question: if rational numbers can approach every real number, can information at rational inputs tell us what happens at all real inputs?

Density supplies the approaching inputs. Continuity makes their outputs approach the output at the destination. We now put these two ideas together. The same method will appear again in functional equations in the next level.

By the density of the rationals and the density of the irrationals, for every \(c\in\mathbb{R}\) we can choose \[r_n\in\mathbb{Q},\qquad s_n\in\mathbb{R}\setminus\mathbb{Q},\qquad r_n\longrightarrow c,\quad s_n\longrightarrow c.\] For example, choose one rational and one irrational in \((c+1/(2n),c+1/n)\) for each \(n\). This also ensures that neither input equals \(c\). Every neighbourhood of \(c\) therefore contains inputs of both types, however small we make that neighbourhood.

The Dirichlet Function: No Point of Continuity

Example 14.6

Two Dense Sets, Two Different Output Values

Consider the Dirichlet function \[D(x)= \begin{cases} 1,&x\in\mathbb{Q},\\ 0,&x\notin\mathbb{Q}. \end{cases}\] Prove that \(D\) is discontinuous at every real number.

Explanation 14.6

Fix any \(c\in\mathbb{R}\), and choose the two sequences above. Then \[D(r_n)=1\longrightarrow1,\qquad D(s_n)=0\longrightarrow0.\] If \(D\) were continuous at \(c\), the sequential criterion for continuity would force both output sequences to converge to \(D(c)\). They cannot: one would require \(D(c)=1\) and the other \(D(c)=0\).

The same obstruction is visible directly in the definition. Take \(\varepsilon_0=1/2\). Given any \(\delta>0\), choose an input \(x\) of the opposite rationality type from \(c\) with \(|x-c|<\delta\). Density makes this possible, and then \[|D(x)-D(c)|=1\ge\varepsilon_0.\] Thus no radius works for this tolerance. Since \(c\) was arbitrary, \(D\) is nowhere continuous.

Remark 14.2

The graph lies on the two horizontal lines \(y=0\) and \(y=1\). On the upper line it has precisely the points with rational input; on the lower line it has precisely the points with irrational input. Neither horizontal line is filled in completely. A finite picture cannot show all these points, but density explains why both output heights occur arbitrarily close to every input.

Changing the Formula on Rational and Irrational Inputs

Example 14.7

An Oscillating Choice of Formula Can Still Be Continuous

Determine the points of continuity of \[P(x)= \begin{cases} x^2,&x\in\mathbb{Q},\\ -x^2,&x\notin\mathbb{Q}. \end{cases}\]

Explanation 14.7

At \(0\), the choice of sign makes no difference to the size of the error: \[P(0)=0,\qquad |P(x)-P(0)|=x^2.\] Given \(\varepsilon>0\), the choice \(\delta=\sqrt{\varepsilon}\) gives \(|P(x)-P(0)|<\varepsilon\) whenever \(|x|<\delta\). Hence \(P\) is continuous at \(0\).

At \(c\ne0\), choose rational \(r_n\to c\) and irrational \(s_n\to c\). The sequence limit laws give \[P(r_n)=r_n^2\longrightarrow c^2,\qquad P(s_n)=-s_n^2\longrightarrow-c^2.\] Since \(c^2\ne-c^2\), these outputs cannot both approach \(P(c)\). Thus \(P\) is discontinuous at every nonzero point, and its only point of continuity is \(0\).

Example 14.8

Two Formulas That Agree at Two Inputs

Now consider \[H(x)= \begin{cases} x,&x\in\mathbb{Q},\\ x^2,&x\notin\mathbb{Q}. \end{cases}\] Find all its points of continuity.

Explanation 14.8

The two formulas have the same value precisely when \(c=c^2\), that is, when \(c=0\) or \(c=1\). Both points really work.

At \(0\), \(H(0)=0\). For \(|x|<1\), each possible formula satisfies \(|H(x)|\le|x|\). Thus \(\delta=\min\{1,\varepsilon\}\) proves continuity.

At \(1\), \(H(1)=1\). If \(|x-1|<1\), then \(|x+1|<3\). For a rational input the error is \(|x-1|\), while for an irrational input it is \[|x^2-1|=|x-1|\,|x+1|<3|x-1|.\] Consequently \(\delta=\min\{1,\varepsilon/3\}\) works for both types of input at once.

At any other \(c\), rational and irrational input sequences give limits \(c\) and \(c^2\), which differ. The sequential criterion rules out continuity there. The exact answer is therefore \[\boxed{\text{$H$ is continuous exactly at $0$ and $1$.}}\] The choice between \(x\) and \(x^2\) has two meeting points; the choice between \(x^2\) and \(-x^2\) has only one. We must check where the formulas agree rather than assume that zero is the only possibility.

[Figure being adapted for the online edition.]

The dashed guides are \(y=x\) and \(y=x^2\); the coloured markers show only finitely many values of \(H\). The guides meet at \(0\) and \(1\). Near either meeting point, values from both formulas approach the same output. Away from them, density keeps both different limiting heights present.

Theorem 14.4

A General Test for Two Dense Branches

Let \(f,g:\mathbb{R}\to\mathbb{R}\) both be continuous at \(c\), and define \[h(x)= \begin{cases} f(x),&x\in\mathbb{Q},\\ g(x),&x\notin\mathbb{Q}. \end{cases}\] Then \(h\) is continuous at \(c\) if and only if \(f(c)=g(c)\).

Show proof

Proof. First suppose \(h\) is continuous at \(c\). Choose rational \(r_n\to c\) and irrational \(s_n\to c\). Continuity of the three functions at \(c\) gives \[h(r_n)=f(r_n)\longrightarrow f(c),\qquad h(s_n)=g(s_n)\longrightarrow g(c),\] while both sequences on the left must converge to \(h(c)\). Uniqueness of a sequence limit therefore gives \(f(c)=h(c)=g(c)\).

Conversely, suppose \(f(c)=g(c)=L\). Then \(h(c)=L\), whichever branch defines it. Given \(\varepsilon>0\), continuity of \(f\) supplies \(\delta_f>0\) such that \(|x-c|<\delta_f\) implies \(|f(x)-L|<\varepsilon\). Continuity of \(g\) supplies \(\delta_g>0\) with the corresponding property. Set \(\delta=\min\{\delta_f,\delta_g\}\). If \(|x-c|<\delta\), then the appropriate estimate applies whether \(x\) is rational or irrational. Thus \(|h(x)-h(c)|<\varepsilon\), proving continuity. ◻

The assumptions that both branch functions are continuous at \(c\) matter. Agreement of their values at just one input does not control their nearby values. The result works because density tests both branches, and continuity tells us the limit of each branch.

An Application to Cauchy’s Functional Equation

Motivation 14.4

Suppose a quantity adds in the same way as its input: \[F(x+y)=F(x)+F(y).\] We expect a straight-line rule \(F(x)=kx\): two equal steps should contribute twice as much, and three equal steps three times as much. Addition immediately confirms this for integer and rational steps. Continuity is the bridge that lets us pass from rational steps to any real step.

This is the promised functional-equation application of density.

Theorem 14.5

Continuous Solutions of the Additive Cauchy Equation

Suppose \(F:\mathbb{R}\to\mathbb{R}\) satisfies \[F(x+y)=F(x)+F(y)\qquad\text{for every }x,y\in\mathbb{R}.\] If \(F\) is continuous at even one point, then \[F(x)=kx\qquad(x\in\mathbb{R}),\qquad\text{where }k=F(1).\] Conversely, every function of this form is continuous and satisfies the equation.

Show proof

Proof. We separate what follows from the equation alone from the step that uses continuity.

First, find the values at integers. Taking \(x=y=0\) gives \(F(0)=2F(0)\), so \(F(0)=0\). Next \(0=F(x+(-x))=F(x)+F(-x)\), hence \(F(-x)=-F(x)\). Repeated addition gives \[F(nx)=nF(x)\qquad(n\in\mathbb{N}).\] Putting \(x=1\) and then using the negative-input identity shows \(F(m)=mk\) for every \(m\in\mathbb{Z}\).

Next, find the values at rationals. Let \(q=m/n\), with \(m\in\mathbb{Z}\) and \(n\in\mathbb{N}\). Since \(nq=m\), \[nF(q)=F(nq)=F(m)=mk.\] Dividing by \(n\) gives \(F(q)=kq\). No continuity has been used yet.

Now bring the given continuity to zero. Let \(a\) be a point where \(F\) is continuous. Given \(\varepsilon>0\), take \(\delta>0\) so that \(|u-a|<\delta\) implies \(|F(u)-F(a)|<\varepsilon\). For \(|t|<\delta\), put \(u=a+t\). Additivity gives \[|F(t)-F(0)|=|F(a+t)-F(a)|<\varepsilon.\] Thus \(F\) is continuous at \(0\).

The same radius works at any fixed \(x\): if \(|u-x|<\delta\), then \[|F(u)-F(x)|=|F(u-x)|<\varepsilon.\] So \(F\) is continuous everywhere.

Finally, use density. Fix any real number \(x\). Choose rational numbers \(q_n\to x\). By continuity and the sequential criterion, \[F(x)=\lim_{n\to\infty}F(q_n) =\lim_{n\to\infty}kq_n=kx.\] This proves the stated form at every real input.

For the converse, \(F(x)=kx\) gives \(F(x+y)=k(x+y)=F(x)+F(y)\). If \(k\ne0\), the estimate \(|F(u)-F(x)|=|k|\,|u-x|\) proves continuity with \(\delta=\varepsilon/|k|\). If \(k=0\), the function is constant and every positive radius works. ◻

Example 14.9

One Value Determines the Whole Function

An additive function \(F:\mathbb{R}\to\mathbb{R}\) is continuous at \(2\) and satisfies \(F(3)=12\). Find \(F(\sqrt2)\).

Explanation 14.9

Continuity at \(2\) is enough for the theorem. Therefore \(F(x)=kx\). The condition \(F(3)=12\) gives \(3k=12\), hence \(k=4\) and \[F(\sqrt2)=4\sqrt2.\] The rational values are forced by addition. Continuity and density are the reason that the same formula holds at the irrational input \(\sqrt2\).

Warning 14.2

Additivity first gives \(F(q)=qF(1)\) for rational \(q\). Merely saying that the rationals are dense does not yet prove the formula at irrational inputs. The step \(F(q_n)\to F(x)\) is precisely where continuity is used. In our next-level functional-equation course we will meet more problems where information on a dense set becomes useful only after this step has been justified.

Agreement on a Dense Set Determines a Continuous Function

Motivation 14.5

Recall a result from our polynomial classes. If two polynomials of degree at most \(n\) agree at \(n+1\) distinct inputs, then they are identical. Indeed, their difference has degree at most \(n\) and has \(n+1\) distinct roots. The root bound forces that difference to be the zero polynomial. The degree restriction is what makes this finite amount of information enough.

For continuous functions there is no degree restriction. Here a dense set supplies the information we need: we can approach any real input through inputs where the two functions already agree. Continuity will carry that equality to the limiting input. This gives a general form of the density argument we just used for Cauchy’s equation.

Theorem 14.6

Agreement on a dense set

Let \(D\subseteq\mathbb{R}\) be dense in \(\mathbb{R}\), and let \(f,g:\mathbb{R}\to\mathbb{R}\) be continuous. If \[f(d)=g(d)\qquad\text{for every }d\in D,\] then \(f(x)=g(x)\) for every \(x\in\mathbb{R}\).

Show proof

Proof. Fix an arbitrary real number \(c\). For each \(n\in\mathbb{N}\), density provides an input \[d_n\in D\cap\left(c-\frac1n,c+\frac1n\right).\] Since \(|d_n-c|<1/n\), the sequence \((d_n)\) converges to \(c\). Continuity of both functions and the sequential criterion for continuity give \[f(d_n)\longrightarrow f(c),\qquad g(d_n)\longrightarrow g(c).\] But \(f(d_n)=g(d_n)\) for every \(n\), because every \(d_n\) belongs to \(D\). Thus these are the same output sequence. Uniqueness of a sequence limit forces \(f(c)=g(c)\). As \(c\) was arbitrary, the functions agree everywhere. ◻

Notice the two jobs in this proof. Density supplies inputs from \(D\) converging to \(c\); continuity identifies the limits of their outputs. The inputs \(d_n\) are allowed to equal \(c\) when \(c\in D\): the sequential criterion for continuity permits this. In fact, the same argument proves \(f(c)=g(c)\) at any point \(c\) where both functions are continuous, provided \(c\) can be approached by a sequence of points of agreement.

Example 14.10

Knowing the values at all rational inputs

A continuous function \(F:\mathbb{R}\to\mathbb{R}\) satisfies \(F(q)=q^2\) for every rational number \(q\). Determine \(F(x)\) for real \(x\).

Explanation 14.10

The function \(G(x)=x^2\) is continuous, as proved directly earlier in this lecture. The functions \(F\) and \(G\) agree on the dense set \(\mathbb{Q}\). The theorem therefore gives \[F(x)=x^2\qquad\text{for every real }x.\] For example, choose rational \(q_n\to\sqrt2\). Then continuity gives \(F(\sqrt2)=\lim F(q_n)=\lim q_n^2=2\). The same reasoning works at every real input.

Warning 14.3

Agreement on a dense set alone does not suffice. The Dirichlet function \(D(x)\) from this lecture agrees with the constant function \(1\) at every rational input, yet it is \(0\) at every irrational input. The missing hypothesis is continuity of \(D\).

An infinite agreement set need not be dense either. The continuous functions \(0\) and \(\sin(\pi x)\) agree at every integer, but at \(x=1/2\) their values are \(0\) and \(1\). Density allows an approximation to every real input; simply having infinitely many agreement points does not guarantee that.

We will use this principle again in the next-level functional-equation course: first identify a formula on a convenient dense set, then use continuity to extend the identity to all real inputs.
