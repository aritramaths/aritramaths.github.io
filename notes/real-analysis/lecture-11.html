Standard Limits and Substitution

Read this lecture online, then continue to the next chapter. Figures and exercises are being adapted separately for the web edition.

Motivation 11.1

The arithmetic laws are now available. We can turn to standard limits that will become useful building blocks, and then use them in substitutions and calculations. The definitions still stand behind every rule: a familiar formula is useful only when its domain and hypotheses fit the expression before us.

Changing the Input in a Known Limit

Suppose \(g(x)\to b\) as \(x\to a\) and \(F(t)\to L\) as \(t\to b\). A substitution \(t=g(x)\) is valid if the values \(g(x)\) lie in the domain of \(F\) and \(g(x)\ne b\) for all sufficiently close admissible \(x\ne a\). Indeed, for a prescribed \(\varepsilon>0\), choose \(\eta>0\) such that \[0<|t-b|<\eta\quad\Longrightarrow\quad |F(t)-L|<\varepsilon.\] Next choose \(\delta>0\) so that \(0<|x-a|<\delta\) implies \(|g(x)-b|<\eta\), reducing \(\delta\) to ensure \(g(x)\ne b\). Then \(0<|g(x)-b|<\eta\), which proves \(F(g(x))\to L\).

There is another useful version: if \(F(b)\) is defined and equals \(L\), the condition \(g(x)\ne b\) can be dropped. At an input where \(g(x)=b\), the output is already exactly \(L\); at the other inputs, use the preceding estimate.

Warning 11.1

Let \(g(x)=0\) for all \(x\), and let \(F(0)=1\) while \(F(t)=0\) for \(t\ne0\). Then \(g(x)\to0\) and \(\lim_{t\to0}F(t)=0\), but \(F(g(x))=1\) always. The limit of \(F\) says nothing about its value at the excluded point \(0\).

Standard Trigonometric Limits

All angles below are measured in radians. On the unit circle, a radian angle equals the corresponding arc length. This is what makes the number \(1\) appear in the next formula.

Formula 11.1

The Fundamental Trigonometric Limit

\[\lim_{x\to0}\frac{\sin x}{x}=1.\]

Geometry 11.1

For \(0<x<\pi/2\), comparison of the inner triangle, sector, and outer triangle in the unit circle gives \[\frac12\sin x<\frac12x<\frac12\tan x, \qquad\text{hence}\qquad \cos x<\frac{\sin x}{x}<1.\] Also \(|\sin u|\le |u|\) for sufficiently small \(u\), by the same comparison and oddness of sine. Thus \[0\le1-\cos x=2\sin^2(x/2)\le\frac{x^2}{2}.\] Combining the inequalities, and using that \(\sin x/x\) is even, gives for \(0<|x|<\pi/2\) the explicit estimate \[\left|\frac{\sin x}{x}-1\right|\le1-\cos x\le\frac{x^2}{2}.\] Given \(\varepsilon>0\), choose \(\delta=\min\{\pi/2,\sqrt{2\varepsilon}\}\). Then \(0<|x|<\delta\) makes the last error strictly less than \(\varepsilon\). This proves the limit directly from its definition.

[Figure being adapted for the online edition.]

The estimate \(|1-\cos x|\le x^2/2\) also proves \(\cos x\to1\) directly. Consequently the quotient law gives \[\lim_{x\to0}\frac{\tan x}{x} =\lim_{x\to0}\frac{\sin x/x}{\cos x}=1.\] Using \(1-\cos x=2\sin^2(x/2)\) gives another standard limit: \[\lim_{x\to0}\frac{1-\cos x}{x^2} =\frac12\lim_{x\to0}\left(\frac{\sin(x/2)}{x/2}\right)^2 =\frac12.\]

Example 11.1

Keep Track of the Scale

Evaluate \[\lim_{x\to0}\frac{\sin5x}{x},\qquad \lim_{x\to0}\frac{\sin2x}{\sin3x},\qquad \lim_{x\to0}\frac{1-\cos3x}{x^2}.\]

Explanation 11.1

Make the standard expressions visible before taking limits: \[\frac{\sin5x}{x}=5\frac{\sin5x}{5x}\longrightarrow5,\] \[\frac{\sin2x}{\sin3x} =\frac23\frac{\sin2x/(2x)}{\sin3x/(3x)}\longrightarrow\frac23,\] \[\frac{1-\cos3x}{x^2} =\frac92\left(\frac{\sin(3x/2)}{3x/2}\right)^2 \longrightarrow\frac92.\] In general \(\sin(ax)/\sin(bx)\to a/b\) for real \(a,b\) with \(b\ne0\). For \(a=0\), the numerator is identically zero; otherwise the same calculation applies. The denominator is nonzero sufficiently near zero because \(\sin(bx)/(bx)\to1\).

Exponential and Logarithmic Standard Limits

Some standard limits, such as the sine limit above, can already be proved with our present tools. Others will need ideas we develop later. The order of discovery can be different from the order of a proof: numerical or geometric evidence can suggest a limit before we know how to justify it. Here we state the exponential limit so that we can complete our collection of standard limits and use it in calculations. We will return to its rigorous justification as we develop the exponential function more fully.

Remark 11.1

We use the familiar real exponential function with \(e^t>0\), \(e^0=1\), \(e^{s+t}=e^se^t\), strict increase, and range \((0,\infty)\). We take the following standard limit as a starting fact: \[\lim_{h\to0}\frac{e^h-1}{h}=1.\] The consequences below are proved from this starting fact. Its proof depends on how the real exponential function is constructed. We define \(\ln:(0,\infty)\to\mathbb{R}\) as the inverse of \(t\mapsto e^t\), and \(a^t=e^{t\ln a}\) for \(a>0\).

First observe that \(e^h\to1\): for \(h\ne0\), \[e^h-1=h\frac{e^h-1}{h}\longrightarrow0.\] The missing value at \(h=0\) also equals \(1\). Hence, if \(t\to b\), \(e^t=e^be^{t-b}\to e^b\). These facts justify exponentiating a finite limit without appealing to differentiation.

Formula 11.2

Exponential and Logarithmic Limits

For \(a>0\), \[\lim_{x\to0}\frac{e^x-1}{x}=1, \qquad \lim_{x\to0}\frac{a^x-1}{x}=\ln a, \qquad \lim_{x\to0}\frac{\ln(1+x)}{x}=1.\] For \(a>0\), \(a\ne1\), \[\lim_{x\to0}\frac{\log_a(1+x)}x=\frac1{\ln a}=\log_a e.\]

Show proof

Proof. For \(a=1\), the second numerator is zero, so its limit is \(0=\ln1\). For \(a\ne1\), put \(h=x\ln a\). Then \(h\to0\) and \(h\ne0\) when \(x\ne0\); therefore \[\frac{a^x-1}{x} =\ln a\,\frac{e^{x\ln a}-1}{x\ln a}\longrightarrow\ln a.\]

For the logarithmic limit put \(t=\ln(1+x)\), with \(x>-1\). We must verify that \(t\to0\). Given \(\eta>0\), the number \[d=\min\{1-e^{-\eta},\ e^\eta-1\}\] is positive. If \(|x|<d\), then \(e^{-\eta}<1+x<e^\eta\). Since exponential is strictly increasing, \(-\eta<t<\eta\). Thus \(t\to0\), and \(t\ne0\) for \(x\ne0\). Since \(x=e^t-1\), \[\frac{\ln(1+x)}x=\frac{t}{e^t-1} =\frac1{(e^t-1)/t}\longrightarrow1.\] Finally \(\log_a(1+x)=\ln(1+x)/\ln a\), giving the last formula. ◻

Formula 11.3

The Standard Power Limit

For \(u>-1\) and \(u\ne0\), \[\lim_{u\to0}(1+u)^{1/u}=e.\] Consequently, within the domain \(1+1/x>0\), \[\lim_{x\to+\infty}\left(1+\frac1x\right)^x=e, \qquad \lim_{x\to-\infty}\left(1+\frac1x\right)^x=e.\]

Show proof

Proof. Write \[(1+u)^{1/u} =\exp\left(\frac{\ln(1+u)}u\right).\] The exponent tends to \(1\), so the expression tends to \(e^1=e\) by the exponential input-change fact proved above. For the two limits at infinity, put \(u=1/x\). In both cases \(u\to0\); the base is positive eventually. ◻

Method 11.1

For any positive base \(b(x)\), write \[b(x)^{c(x)}=\exp\bigl(c(x)\ln b(x)\bigr).\] This reduces the power problem to the limit of a product. If the original positive expression tends to \(L>0\), taking its logarithm gives a limit of \(\ln L\). Passing the limit inside \(\ln\) is exactly what continuity of the logarithm means here. We will justify and study this step in detail in the chapter on continuity.

Suppose \(v(x)\to0\), \(1+v(x)>0\), and \(w(x)v(x)\to B\in\mathbb{R}\). Then \[(1+v(x))^{w(x)}\longrightarrow e^B.\] To see this, define \(H(0)=1\) and \(H(t)=\ln(1+t)/t\) for \(t\ne0\) near \(0\). The logarithmic standard limit says \(H(t)\to1\), including the assigned value at \(0\). Therefore \[w(x)\ln(1+v(x))=w(x)v(x)H(v(x))\longrightarrow B.\] Now we go back from the logarithm to the original power. By continuity of the exponential, the limit is \(\exp(B)=e^B\). This also covers inputs where \(v(x)=0\): then the base is \(1\) and both sides of the logarithmic identity are zero.

Example 11.2

Scaling an Exponential or Logarithmic Error

Evaluate \[\lim_{x\to0}\frac{e^{4x}-1}{x},\qquad \lim_{x\to0}\frac{\ln(1+2x)}x,\qquad \lim_{x\to+\infty}\left(1+\frac1{7x}\right)^x.\]

Explanation 11.2

For the first two limits, isolate the small input: \[\frac{e^{4x}-1}{x}=4\frac{e^{4x}-1}{4x}\longrightarrow4, \qquad \frac{\ln(1+2x)}x=2\frac{\ln(1+2x)}{2x}\longrightarrow2.\] For the last one, use \(v(x)=1/(7x)\) and \(w(x)=x\). Then \(v(x)\to0\) and \(w(x)v(x)=1/7\), so the limit is \(e^{1/7}\).

Example 11.3

Nine Uses of the Standard Exponential Limits

Find the following limits. Here \(k,m\in\mathbb{R}\) are fixed and \(a>0\).

\(\displaystyle\lim_{x\to+\infty}(1+1/x)^{7x}\).

\(\displaystyle\lim_{x\to0}(1+x)^{1/(3x)}\).

\(\displaystyle\lim_{x\to+\infty}\left(\frac{x}{1+x}\right)^x\).

\(\displaystyle\lim_{x\to+\infty}(1+k/x)^{mx}\).

\(\displaystyle\lim_{x\to0}\frac{\ln(1+x)}{3^x-1}\).

\(\displaystyle\lim_{x\to0}\frac{e^{4x}-1}{\tan x}\).

\(\displaystyle\lim_{x\to0}\frac{\ln(a+x)-\ln a}{x}\).

\(\displaystyle\lim_{x\to0}\frac{e^x-e^{-x}}{\sin x}\).

\(\displaystyle\lim_{x\to e}\frac{\ln x-1}{x-e}\).

Explanation 11.3

(a) The logarithm of the expression is \[7x\ln(1+1/x)=7\frac{\ln(1+1/x)}{1/x}\longrightarrow7.\] Exponentiating gives \(e^7\).

(b) Its logarithm is \(\tfrac13\ln(1+x)/x\to1/3\), so the answer is \(e^{1/3}\). Both sides are permitted near zero because \(1+x>0\) there.

(c) Since \(x/(1+x)=(1+1/x)^{-1}\), its logarithm is \(-x\ln(1+1/x)\to-1\). The answer is \(e^{-1}\).

(d) The base is positive for all sufficiently large \(x\), even if \(k<0\). If \(k\ne0\), \[mx\ln(1+k/x)=mk\frac{\ln(1+k/x)}{k/x}\longrightarrow mk.\] The limit is \(e^{mk}\). When \(k=0\), the expression is identically \(1\), which agrees with the formula.

(e) Separate the two standard quotients: \[\frac{\ln(1+x)}{3^x-1} =\frac{\ln(1+x)}x\,\frac{x}{3^x-1} \longrightarrow\frac1{\ln3}.\] The second factor is allowed because \((3^x-1)/x\to\ln3\ne0\).

(f) Divide numerator and denominator by \(x\): \[\frac{e^{4x}-1}{\tan x} =4\frac{e^{4x}-1}{4x}\,\frac{x}{\tan x}\longrightarrow4.\]

(g) Use \(\ln(a+x)-\ln a=\ln(1+x/a)\). Then \[\frac{\ln(a+x)-\ln a}{x} =\frac1a\frac{\ln(1+x/a)}{x/a}\longrightarrow\frac1a.\] The assumption \(a>0\) ensures that the logarithms are defined near zero.

(h) Split the numerator and track the minus sign: \[\frac{e^x-e^{-x}}{\sin x} =\left(\frac{e^x-1}{x} +\frac{e^{-x}-1}{-x}\right)\frac{x}{\sin x} \longrightarrow(1+1)\cdot1=2.\]

(i) Put \(t=x/e-1\). Then \(x-e=et\) and \(\ln x-1=\ln(1+t)\). Thus \[\frac{\ln x-1}{x-e} =\frac1e\frac{\ln(1+t)}t\longrightarrow\frac1e.\]

Example 11.4

A Small Change Raised to a Growing Power

Find \(\displaystyle\lim_{x\to+\infty}(1+1/x^2)^x\).

Explanation 11.4

The base tends to \(1\) and the exponent tends to infinity; this description alone does not determine the answer. Take logarithms: \[x\ln(1+1/x^2) =\frac1x\,\frac{\ln(1+1/x^2)}{1/x^2}\longrightarrow0\cdot1=0.\] The original expression therefore tends to \(e^0=1\).

Example 11.5

When Both the Base and the Exponent Vary

Evaluate: \[\text{(a) }\lim_{x\to1}\left(\frac{1+x}{2+x}\right)^{(1-\sqrt{x})/(1-x)},\] \[\text{(b) }\lim_{x\to+\infty} \left(\frac{x^2+2x-1}{2x^2-3x-2}\right)^{(2x+1)/(x-1)}.\]

Explanation 11.5

(a) The base tends to \(2/3>0\). Rationalising the exponent gives \[\frac{1-\sqrt{x}}{1-x}=\frac1{1+\sqrt{x}}\longrightarrow\frac12.\] For completeness, if a positive base \(b(x)\to B>0\), write \(b(x)=B(1+u(x))\) with \(u(x)\to0\). Then \(\ln b(x)=\ln B+\ln(1+u(x))\to\ln B\). Consequently the logarithm of the expression tends to \(\tfrac12\ln(2/3)\). The required answer is \(\sqrt{2/3}\).

(b) Divide the numerator and denominator of the base by \(x^2\): \[\frac{1+2/x-1/x^2}{2-3/x-2/x^2}\longrightarrow\frac12.\] Also \((2x+1)/(x-1)=(2+1/x)/(1-1/x)\to2\). The base is positive on a sufficiently large positive tail. By the same logarithmic argument as in (a), the limit is \((1/2)^2=1/4\).

Example 11.6

Four Powers with a Base Approaching One

Evaluate

\(\displaystyle\lim_{x\to+\infty}\left(\frac{2x^2+3}{2x^2+5}\right)^{8x^2+3}\);

\(\displaystyle\lim_{x\to0}\left(\frac{1+\tan x}{1+\sin x}\right)^{1/\sin x}\);

\(\displaystyle\lim_{x\to1}(1+\sin\pi x)^{\cot\pi x}\);

\(\displaystyle\lim_{x\to a}\left(\frac{\sin x}{\sin a}\right)^{1/(x-a)}\), where \(a\notin\pi\mathbb{Z}\).

Explanation 11.6

Write the base as \(1+w(x)\), where \[w(x)=-\frac{2}{2x^2+5}.\] Then \(w(x)\to0\) and \[(8x^2+3)w(x) =-\frac{16x^2+6}{2x^2+5}\longrightarrow-8.\] The logarithm of the expression therefore tends to \(-8\), and the required limit is \(\boxed{e^{-8}}\).

Here the deviation of the base from \(1\) is \[w(x)=\frac{\tan x-\sin x}{1+\sin x}.\] For small nonzero \(x\), \[\frac{w(x)}{\sin x} =\frac{1/\cos x-1}{1+\sin x} =\frac{1-\cos x}{\cos x(1+\sin x)}\longrightarrow0.\] Thus the logarithm tends to \(0\), and the power tends to \(\boxed1\). Notice that the exponent by itself has no finite limit. We control the product appearing after taking a logarithm.

Put \(w(x)=\sin\pi x\). Then \(w(x)\to0\) and \[(\cot\pi x)w(x)=\cos\pi x\longrightarrow-1.\] Consequently the answer is \(\boxed{e^{-1}}\).

Since \(\sin a\ne0\), the ratio \(\sin x/\sin a\) is positive for \(x\) sufficiently close to \(a\). Set \[w(x)=\frac{\sin x-\sin a}{\sin a}.\] The sine difference identity gives \[\begin{aligned} \frac{w(x)}{x-a} &=\frac{2\cos((x+a)/2)\sin((x-a)/2)}{(x-a)\sin a}\\ &=\frac{\cos((x+a)/2)}{\sin a} \frac{\sin((x-a)/2)}{(x-a)/2} \longrightarrow\frac{\cos a}{\sin a}=\cot a. \end{aligned}\] Therefore the limit is \(\boxed{e^{\cot a}}\). This proof uses a trigonometric identity and the fundamental sine limit; no differentiation is needed.

Example 11.7

Two Per Cent Growth for a Century

A population increases by \(2\%\) each year. By what factor does it increase in \(100\) years? How can the standard exponential limit help us estimate the answer?

Explanation 11.7

Let the initial population be \(P\). After one year it is \(1.02P\), after two years it is \((1.02)^2P\), and after \(100\) years it is \((1.02)^{100}P\). Thus the exact multiplying factor is \[\boxed{(1.02)^{100}=\left(1+\frac1{50}\right)^{100} \approx7.24465.}\] To connect this with the standard limit, write \[\left(1+\frac1{50}\right)^{100} =\left[\left(1+\frac1{50}\right)^{50}\right]^2.\] The expression inside the square brackets is a finite-stage approximation to \(e\). Replacing it by \(e\) gives the rough estimate \(e^2\approx7.38906\). This is close to, but different from, the exact factor: it overestimates it by about \(0.14441\), or about \(1.99\%\) of the exact factor. A limit provides an approximation here, not an exact equality at \(n=50\).

More Exponential and Power Examples

Remark 11.2

We will use \(\ln y/y\to0\) as \(y\to+\infty\). Here is a proof using only sequences already studied. Put \(n=\lfloor\ln y\rfloor\). Then \(n\to\infty\), \(\ln y<n+1\) and \(y\ge e^n\), so \[0\le\frac{\ln y}{y}\le\frac{n+1}{e^n}\longrightarrow0.\] The ratio criterion shows that the last sequence tends to zero: the ratio of consecutive terms tends to \(1/e<1\). For a prescribed \(\varepsilon>0\), choose \(N\) so that \((n+1)/e^n<\varepsilon\) for \(n\ge N\). Then \(y>e^N\) ensures \(n\ge N\), so \(\ln y/y<\varepsilon\).

Example 11.8

Eleven Exponential and Power Limits

Evaluate the following limits on their real domains. Assume \(a>0\) in part (c), and \(\alpha,\beta\in\mathbb{R}\) in part (k).

\(\displaystyle\lim_{x\to+\infty}(1+4/x)^{x+3}\);

\(\displaystyle\lim_{x\to0}\frac{e^{-x}-1}{x}\);

\(\displaystyle\lim_{x\to0}\frac{a^{2x}-1}{x}\);

\(\displaystyle\lim_{x\to0}(1+3\tan^2x)^{\cot^2x}\);

\(\displaystyle\lim_{x\to\pi/4}(\sin2x)^{\tan^22x}\);

\(\displaystyle\lim_{x\to+\infty}\left(\frac{2x-1}{2x+1}\right)^x\);

\(\displaystyle\lim_{x\to\pi/2}(\tan x)^{\tan2x}\);

\(\displaystyle\lim_{x\to\pi/2}(\sin x)^{\tan x}\);

\(\displaystyle\lim_{x\to+\infty}\left(\frac{3x^2+2x+1}{x^2+x+2}\right)^{(6x+1)/(3x+2)}\);

\(\displaystyle\lim_{x\to+\infty}\left(\frac{1+3x}{2+3x}\right)^{(1-\sqrt{x})/(1-x)}\);

\(\displaystyle\lim_{x\to0}\frac{e^{\alpha x}-e^{\beta x}}{x}\).

Explanation 11.8

The base is \(1+w\) with \(w=4/x\to0\), and \((x+3)w=4+12/x\to4\). Taking logarithms as above gives the answer \(\boxed{e^4}\).

With \(u=-x\), \[\frac{e^{-x}-1}{x}=-\frac{e^u-1}{u}\longrightarrow\boxed{-1}.\]

Put \(u=2x\). Then \[\frac{a^{2x}-1}{x}=2\frac{a^u-1}{u}\longrightarrow\boxed{2\ln a}.\] For \(a=1\) the numerator is identically zero, in agreement with the formula.

Take \(w=3\tan^2x\). The product of the exponent and \(w\) is exactly \[\cot^2x\cdot3\tan^2x=3\] where the expression is defined. The logarithm therefore tends to \(3\), and the answer is \(\boxed{e^3}\).

Put \(t=2x-\pi/2\). Then \(t\to0\), \(\sin2x=\cos t\) and \(\tan^22x=\cot^2t\). The base is positive close to the point. Moreover, \[\begin{aligned} (\cos t-1)\cot^2t &=-\frac{\sin^2t}{1+\cos t}\frac{\cos^2t}{\sin^2t}\\ &=-\frac{\cos^2t}{1+\cos t}\longrightarrow-\frac12. \end{aligned}\] The answer is \(\boxed{e^{-1/2}}\).

Write the base as \(1-2/(2x+1)\). Since \[x\left(-\frac2{2x+1}\right)\longrightarrow-1,\] the limit is \(\boxed{e^{-1}}\).

The usual real variable power \(u^v=e^{v\ln u}\) requires \(u>0\). Near \(\pi/2\), the base \(\tan x\) is positive on the left, so this is a limit along that part of its natural real domain. Put \(y=\tan x\); then \(y\to+\infty\) and \[(\tan2x)\ln(\tan x) =\frac{2y}{1-y^2}\ln y =-\frac{2y^2}{y^2-1}\frac{\ln y}{y}\longrightarrow0.\] The logarithm tends to zero, so the power tends to \(\boxed1\). A two-sided interpretation with an arbitrary real exponent and a negative base would not define a real function on a right-hand interval.

Here \(\sin x>0\) on both sides of \(\pi/2\) close to the point. The exponent can tend to different infinities, but \[(\tan x)(\sin x-1) =\frac{\sin x}{\cos x}\frac{-\cos^2x}{1+\sin x} =-\frac{\sin x\cos x}{1+\sin x}\longrightarrow0.\] The logarithmic factor \(\ln(\sin x)/(\sin x-1)\) tends to \(1\), so the logarithm of the whole expression tends to zero. Hence the two-sided limit is \(\boxed1\).

The base tends to \(3\) and the exponent to \(2\). More explicitly, the logarithm is \[\frac{6x+1}{3x+2}\ln\left(\frac{3x^2+2x+1}{x^2+x+2}\right) \longrightarrow2\ln3.\] Exponentiating gives \(\boxed9\). The logarithm has the stated limit because, if a positive \(u(x)\to3\), then \(\ln u(x)=\ln3+\ln(u(x)/3)\) and \(\ln(u(x)/3)\to0\) by the standard logarithmic limit.

For \(x\ne1\), rationalising the exponent gives \[\frac{1-\sqrt{x}}{1-x}=\frac1{1+\sqrt{x}}\longrightarrow0.\] The base tends to \(1\) through positive values, so its logarithm tends to zero. The logarithm of the power is their product and tends to zero; the answer is \(\boxed1\).

Subtract and add \(1\) in the numerator: \[\frac{e^{\alpha x}-e^{\beta x}}x =\frac{e^{\alpha x}-1}{x}-\frac{e^{\beta x}-1}{x} \longrightarrow\boxed{\alpha-\beta}.\] If a parameter is zero, its corresponding numerator is identically zero. Thus the formula covers all real \(\alpha\) and \(\beta\).

Root and Integer-Power Limits

Let \(k\) be a positive integer, \(x\) be sufficiently near \(0\), and \(y=(1+x)^{1/k}>0\). The factorisation \[x=y^k-1=(y-1)(1+y+\cdots+y^{k-1})\] shows first that \[|y-1|=\frac{|x|}{1+y+\cdots+y^{k-1}}\le |x|.\] Thus \(y\to1\) by a direct error bound. For \(x\ne0\), we may divide and obtain \[\frac{(1+x)^{1/k}-1}{x} =\frac1{1+y+\cdots+y^{k-1}}\longrightarrow\frac1k.\] Only a finite algebraic sum is involved.

Formula 11.4

Radical and Integer-Power Limits

For every positive integer \(k\), \[\lim_{x\to0}\frac{(1+x)^{1/k}-1}{x}=\frac1k.\] For integers \(p,q\) with \(q\ne0\), \[\lim_{x\to1}\frac{x^p-1}{x^q-1}=\frac pq.\]

Show proof

Proof. The radical formula has just been established. For the second formula, a positive integer \(m\) gives \[\frac{x^m-1}{x-1}=1+x+\cdots+x^{m-1}\longrightarrow m.\] For a negative integer \(m=-r\), where \(r>0\), \[\frac{x^{-r}-1}{x-1} =-\frac1{x^r}\frac{x^r-1}{x-1}\longrightarrow-r=m.\] For \(m=0\), the numerator is identically zero. Thus the numerator and denominator of \[\frac{x^p-1}{x^q-1} =\frac{(x^p-1)/(x-1)}{(x^q-1)/(x-1)}\] have limits \(p\) and \(q\ne0\); the quotient law gives \(p/q\). All expressions are considered near \(1\), where \(x>0\), and away from \(x=1\). ◻

For example, rationalising gives \[\lim_{x\to0}\frac{\sqrt{1+4x}-1}{x} =\lim_{x\to0}\frac4{\sqrt{1+4x}+1}=2.\] The general root limit is the same factorisation idea with more terms.

Theorem 11.1

Taking a Root of a Moving Input

Let \(k\) be a positive integer. For \(b\ge0\), with inputs \(t\ge0\), \[\lim_{t\to b}t^{1/k}=b^{1/k}.\] If \(k\) is odd, the same assertion holds for every \(b\in\mathbb{R}\), with the real \(k\)th root taken at every real input.

Show proof

Proof. For \(b>0\), put \(r=t^{1/k}\ge0\) and \(s=b^{1/k}>0\). The finite factorisation gives \[|t^{1/k}-b^{1/k}| =\frac{|t-b|}{r^{k-1}+r^{k-2}s+\cdots+s^{k-1}} \le\frac{|t-b|}{s^{k-1}}.\] The denominator includes the positive term \(s^{k-1}\) (for \(k=1\) it is simply \(1\)). Thus \(\delta=\varepsilon s^{k-1}\) gives a root error less than \(\varepsilon\) whenever \(0<|t-b|<\delta\).

At \(b=0\), choose \(\delta=\varepsilon^k\): then \(0\le t<\delta\) gives \(t^{1/k}<\varepsilon\). For odd \(k\) the same argument allows negative inputs, since \(|t^{1/k}|=|t|^{1/k}\). Finally, for \(b<0\) and odd \(k\), first restrict to \(|t-b|<|b|/2\), so \(t<0\). The positive-input result applied to \(-t\to-b\) proves the assertion, because the root errors are equal. Take the minimum of the positive-input radius and \(|b|/2\). ◻

These error bounds also permit a moving input \(t=g(x)\to b\), including points where \(g(x)=b\). For example, \(g(x)\to8\) gives \(\sqrt[3]{g(x)}\to2\), and \(g(x)\to-1\) gives \(\sqrt[3]{g(x)}\to-1\).

Calculating Limits by Algebra

Motivation 11.2

The definition tells us what a limit means. The laws tell us how to calculate it. Our first question in a calculation should be: can we use the quotient law immediately? If the denominator tends to a nonzero number, we can. If both numerator and denominator tend to zero, look for a simplification. In these examples, factoring or multiplying by a conjugate reveals a common factor that can be cancelled on a deleted neighbourhood. The symbol \(0/0\) is a signal to investigate; it is not a number.

Example 11.9

Cancellation and Rationalisation

Find the following limits. In (d), \(p,q\in\mathbb{Z}\) with \(q\ne0\); in (h), \(a>0\) and \(a\ne1\).

\(\displaystyle\lim_{x\to1}\frac{4x^5+9x+7}{3x^6+x^3+1}\).

\(\displaystyle\lim_{x\to2}\frac{x^3+3x^2-9x-2}{x^3-x-6}\).

\(\displaystyle\lim_{x\to-1}\frac{x+1}{\sqrt{6x^2+3}+3x}\).

\(\displaystyle\lim_{x\to1}\frac{x^p-1}{x^q-1}\).

\(\displaystyle\lim_{x\to0}\frac{\sqrt{9+5x+4x^2}-3}{x}\).

\(\displaystyle\lim_{x\to2}\frac{\sqrt[3]{10-x}-2}{x-2}\).

\(\displaystyle\lim_{x\to2}\frac{\sqrt{x+7}-3\sqrt{2x-3}}{\sqrt[3]{x+6}-2\sqrt[3]{3x-5}}\).

\(\displaystyle\lim_{x\to3}\log_a\left(\frac{x-3}{\sqrt{x+6}-3}\right)\).

\(\displaystyle\lim_{x\to1}\frac{x^3-x^2-x+1}{x^3-3x+2}\).

\(\displaystyle\lim_{x\to1}\frac{\sqrt{x+8}-\sqrt{8x+1}}{\sqrt{5-x}-\sqrt{7x-3}}\).

Explanation 11.9

(a) The denominator tends to \(3+1+1=5\ne0\). Therefore the quotient law gives \[\frac{4+9+7}{3+1+1}=4.\]

(b) Direct substitution gives \(0/0\), so it does not settle the problem. Factor both polynomials: \[x^3+3x^2-9x-2=(x-2)(x^2+5x+1),\qquad x^3-x-6=(x-2)(x^2+2x+3).\] For \(x\ne2\) their quotient equals \((x^2+5x+1)/(x^2+2x+3)\). The latter denominator tends to \(11\), so the required limit is \(15/11\).

(c) Multiply by the conjugate. For \(x\) near \(-1\), \(x\ne-1\), \[\frac{x+1}{\sqrt{6x^2+3}+3x} =\frac{(x+1)(\sqrt{6x^2+3}-3x)}{3-3x^2} =\frac{\sqrt{6x^2+3}-3x}{3(1-x)}.\] The final denominator tends to \(6\), while its numerator tends to \(6\). The limit is \(1\).

(d) The integer-power formula above applies since \(q\ne0\): after dividing both differences by \(x-1\), their limits are \(p\) and \(q\). The limit of the quotient is \(p/q\).

(e) Conjugation removes the radical difference: \[\frac{\sqrt{9+5x+4x^2}-3}{x} =\frac{5+4x}{\sqrt{9+5x+4x^2}+3}\longrightarrow\frac56.\]

(f) Put \(u=\sqrt[3]{10-x}\), so \(u\to2\). Since \((u-2)(u^2+2u+4)=u^3-8=2-x\), \[\frac{\sqrt[3]{10-x}-2}{x-2} =-\frac1{u^2+2u+4}\longrightarrow-\frac1{12}.\]

(g) Every difference vanishes at \(x=2\). We extract \(x-2\) from each. Write \(u=\sqrt[3]{x+6}\) and \(v=\sqrt[3]{3x-5}\). Then \[\frac{\sqrt{x+7}-3\sqrt{2x-3}}{x-2} =\frac1{\sqrt{x+7}+3}-\frac6{\sqrt{2x-3}+1} \longrightarrow\frac16-3=-\frac{17}{6},\] where we first wrote the numerator as \((\sqrt{x+7}-3)-3(\sqrt{2x-3}-1)\). Similarly, \[\frac{u-2v}{x-2} =\frac1{u^2+2u+4}-\frac6{v^2+v+1} \longrightarrow\frac1{12}-2=-\frac{23}{12}.\] The second limit is nonzero. Dividing these two limits gives \(34/23\).

(h) For \(x\ne3\), rationalisation gives \[\frac{x-3}{\sqrt{x+6}-3}=\sqrt{x+6}+3\longrightarrow6.\] The expression is positive near \(3\). To justify passing to the logarithm, write its value as \(6(1+u)\), where \(u\to0\). Then \(\log_a(6(1+u))=\log_a6+\ln(1+u)/\ln a\to\log_a6\), because the standard logarithmic limit implies \(\ln(1+u)\to0\).

(i) The factorisations are \[x^3-x^2-x+1=(x-1)^2(x+1),\qquad x^3-3x+2=(x-1)^2(x+2).\] After cancellation for \(x\ne1\), the quotient is \((x+1)/(x+2)\), so its limit is \(2/3\).

(j) Rationalise the numerator and denominator separately: \[\sqrt{x+8}-\sqrt{8x+1} =\frac{-7(x-1)}{\sqrt{x+8}+\sqrt{8x+1}},\] \[\sqrt{5-x}-\sqrt{7x-3} =\frac{-8(x-1)}{\sqrt{5-x}+\sqrt{7x-3}}.\] Their quotient, for \(x\ne1\), is \[\frac78\, \frac{\sqrt{5-x}+\sqrt{7x-3}}{\sqrt{x+8}+\sqrt{8x+1}} \longrightarrow\frac78\cdot\frac46=\frac7{12}.\]

First Look at One-Sided Limits

Motivation 11.3

On the real input line, every nearby \(x\ne c\) lies either to the left or to the right of \(c\). There is no third side. Although the graph is drawn in \(\mathbb{R}^2\), the input here moves in \(\mathbb{R}\); the plane itself has many directions of approach.

Think of two roads to the same place. If both sides bring the output to the same number \(L\), we expect a single limit. If the destinations differ, there cannot be one answer for the unrestricted approach. We still need to control all inputs on each side, not merely test one chosen sequence from each. We will define both approaches now and see what happens when the two answers differ.

Definition 11.1

Right- and Left-Hand Limits

Let \(f:A\to\mathbb{R}\) and \(c\in\mathbb{R}\). To discuss a right-hand limit, assume that every interval \((c,c+r)\), \(r>0\), contains a point of \(A\). We write \[\lim_{x\to c^+}f(x)=L\] if, for every \(\varepsilon>0\), there exists \(\delta>0\) such that \[x\in A,\qquad 0<x-c<\delta \quad\Longrightarrow\quad |f(x)-L|<\varepsilon.\] For a left-hand limit, assume that every \((c-r,c)\) contains a point of \(A\). The notation \(\lim_{x\to c^-}f(x)=L\) means that, for every \(\varepsilon>0\), some \(\delta>0\) satisfies \[x\in A,\qquad 0<c-x<\delta \quad\Longrightarrow\quad |f(x)-L|<\varepsilon.\] The alternative notations \(f(c+0)\) and \(f(c-0)\) denote these limits, when they exist.

The small \(+\) or \(-\) describes the side from which the input approaches; it does not prescribe the sign of the answer. For example, a right-hand limit can be negative. As before, the value \(f(c)\) is excluded from the definition.

Example 11.10

Two Formulas Meeting at One Input

Find both one-sided limits at \(1\) for \[f(x)=\begin{cases}-2x+3,&x\le1,\\3x-5,&x>1.\end{cases}\]

Explanation 11.10

When \(x\) approaches \(1\) from the left, we use only the first formula. Thus \[\lim_{x\to1^-}f(x)=-2\cdot1+3=1.\] This can also be checked directly: for \(x<1\), \(|f(x)-1|=|-2x+2|=2|x-1|\), so \(\delta=\varepsilon/2\) works. On the right, the second formula gives \[\lim_{x\to1^+}f(x)=3\cdot1-5=-2;\] here \(|f(x)-(-2)|=3|x-1|\), and \(\delta=\varepsilon/3\) works. If a full limit existed, its \(\delta\) would work on each side and both sides would have to approach the same number. They do not, so \(\lim_{x\to1}f(x)\) does not exist. The value \(f(1)=1\) cannot change either answer.
