Why Do We Need Another Counting Method?

In Lecture 1, we learned how to count using the Addition Principle and the Multiplication Principle. In Lecture 2, we learned permutations, combinations, repetition, and circular arrangements.

The next step is to learn how to change a counting problem into another counting problem. This is useful because the original objects may be difficult to count directly, while another related collection may be much easier.

For example, the following questions look different:

  • How many subsets does a set with nn elements have?

  • How many binary strings of length nn are there?

But these two questions have the same answer because every subset can be matched with exactly one binary string.

This kind of matching is the main idea of the Bijection Principle.

Remark

The main theme of this lecture is: If direct counting is difficult, count a cleaner equivalent object.\boxed{\text{If direct counting is difficult, count a cleaner equivalent object.}} Sometimes the cleaner object is obtained by a one-to-one matching. Sometimes it is obtained by counting the complement. Sometimes we must correct overcounting using the Principle of Inclusion and Exclusion.

The Bijection Principle: Counting by Matching

We first explain the idea without using heavy function language.

Suppose we have two collections of objects, say Set A and Set B. If every object of Set A can be paired with exactly one object of Set B, and every object of Set B is paired with exactly one object of Set A, then the two sets must have the same number of objects.

This perfect matching is called a bijection.

Theorem 3.1

Bijection Principle, Revisited

Let AA and BB be two finite sets. If the objects of AA can be matched with the objects of BB in a perfect one-to-one way, then |A|=|B|.|A|=|B|. Such a perfect one-to-one matching is called a bijection.

Remark

For this course, whenever we use a bijection, we shall clearly mention two sets: Set A↔Set B.\boxed{\text{Set A}} \qquad \longleftrightarrow \qquad \boxed{\text{Set B}}. Then we shall explain why every object on the left gives exactly one object on the right, and every object on the right comes from exactly one object on the left.

Remark

For students who know functions: a bijection is a function which is both one-one and onto. But we shall mostly use the simpler phrase one-to-one correspondence.

Subsets and Binary Sequences

The first important example of bijection is between subsets and binary sequences.

Theorem 3.2

If a finite set XX has nn elements, then the number of subsets of XX is 2n.2^n. Equivalently, |𝒫(X)|=2n,|\mathcal P(X)|=2^n, where 𝒫(X)\mathcal P(X) denotes the power set of XX.

Proof.

Let X={a1,a2,…,an}.X=\{a_1,a_2,\ldots,a_n\}. We compare two sets.

Set A: all subsets of XX.

Set B: all binary sequences of length nn.

Given a subset S⊆XS\subseteq X, we form a binary sequence b1b2⋯bnb_1b_2\cdots b_n by the rule bi={1,if ai∈S,0,if ai∉S.b_i= \begin{cases} 1, & \text{if }a_i\in S,\\ 0, & \text{if }a_i\notin S. \end{cases}

So Set A and Set B are in bijection. By Theorem 3.1 (Bijection Principle, Revisited), they have the same size.

But by Theorem 1.6 (Number of kk-ary Sequences), the number of binary sequences of length nn is 2n.2^n. Therefore, |𝒫(X)|=2n.|\mathcal P(X)|=2^n.

Shortest Routes on a Grid

Grid-path problems are one of the most useful applications of the Bijection Principle. A path on a grid can be translated into a sequence of letters.

Suppose a person moves from the lower-left corner to the upper-right corner of a rectangular grid, and the person is allowed to move only: R=one step to the right,U=one step upward.R=\text{one step to the right}, \qquad U=\text{one step upward}. Then every shortest route is simply a sequence of RR's and UU's.

Example 3.3

Shortest Routes on a 4×34\times 3 Grid

A student walks from XX to YY on the street grid below. The student may move only right or up, and wants to take a shortest route. How many shortest routes are possible?

Solution.
Tools to recall.

Theorem 2.4 (Bijection Principle); Theorem 3.3 (shortest-path count)

Every shortest route from XX to YY must consist of: 4 right movesand3 upward moves.4\text{ right moves} \quad\text{and}\quad 3\text{ upward moves}. So each shortest route corresponds to a sequence of 77 symbols containing exactly four RR's and three UU's.

We now identify the two sets.

Set A: shortest routes from XX to YY.

Set B: sequences of length 77 with four RR's and three UU's.

Given a path, write down RR for each right move and UU for each upward move. This gives exactly one sequence. Conversely, any sequence with four RR's and three UU's gives exactly one shortest path.

Thus, Set A and Set B are in bijection.

So the number of shortest routes is the number of ways to choose the positions of the four RR's among the seven positions: (74).\binom{7}{4}. Equivalently, we may choose the positions of the three UU's: (73).\binom{7}{3}. Hence the number of shortest routes is (74)=(73)=35.\boxed{\binom{7}{4}=\binom{7}{3}=35}.

Theorem 3.3

Shortest Routes on a Rectangular Grid

If a shortest route needs exactly mm right moves and nn upward moves, then the number of shortest routes is (m+nm)=(m+nn).\binom{m+n}{m}=\binom{m+n}{n}.

Proof.

Every shortest route is a sequence of m+nm+n moves. Among these moves, mm are right moves and nn are upward moves.

So the route is determined by choosing which mm of the m+nm+n positions contain right moves. This gives (m+nm).\binom{m+n}{m}. Equivalently, we can choose which nn positions contain upward moves, giving (m+nn).\binom{m+n}{n}.

Example 3.4

A Larger Street Network

In the grid below, point AA is the lower-left corner and point BB is the upper-right corner. A shortest route from AA to BB uses only right and upward moves. How many shortest routes are there from AA to BB?

Solution.

Every shortest route from AA to BB uses 7 right movesand6 upward moves.7\text{ right moves} \quad\text{and}\quad 6\text{ upward moves}. Thus each route corresponds to a sequence of 1313 moves containing seven RR's and six UU's.

By Theorem 3.3 (Shortest Routes on a Rectangular Grid), the number of routes is (137)=(136).\binom{13}{7}=\binom{13}{6}. Thus, the answer is (137).\boxed{\binom{13}{7}}.

Example 3.5

Shortest Routes Through a Fixed Point

In the same grid, find the number of shortest routes from AA to BB that pass through the point CC shown below.

Solution.

A route from AA to BB through CC is made in two stages: A→CandC→B.A\to C \qquad\text{and}\qquad C\to B.

From AA to CC, the path uses 4 right moves and 4 upward moves.4\text{ right moves and }4\text{ upward moves}. So the number of shortest paths from AA to CC is (84).\binom{8}{4}.

From CC to BB, the path uses 3 right moves and 2 upward moves.3\text{ right moves and }2\text{ upward moves}. So the number of shortest paths from CC to BB is (53).\binom{5}{3}.

By Theorem 1.4 (Multiplication Principle), the number of shortest routes from AA to BB through CC is (84)(53).\binom{8}{4}\binom{5}{3}. Hence, the answer is (84)(53).\boxed{\binom{8}{4}\binom{5}{3}}.

Example 3.6

Shortest Routes Through a Fixed Edge

In the grid below, find the number of shortest routes from AA to BB that contain the edge CDCD.

Solution.
Tools to recall.

Theorem 3.3 (shortest-path count)

If a shortest route contains the edge CDCD, then the route must be built as A→C,C→D,D→B.A\to C, \qquad C\to D, \qquad D\to B. The middle part C→DC\to D is fixed, because it is the given edge.

Therefore, the number of shortest paths containing the edge CDCD is (84)(42).\binom{8}{4}\binom{4}{2}. Hence, the answer is (84)(42).\boxed{\binom{8}{4}\binom{4}{2}}.

Remark

A grid-path problem is a bijection problem because every route is matched with a sequence of moves. The geometry is converted into a word made of symbols such as RR and UU.

Remark

In three-dimensional grid problems, a path may use three kinds of moves, such as XX, YY, and ZZ. If a route uses aa moves of one type, bb moves of a second type, and cc moves of a third type, then the number of shortest routes is (a+b+c)!a!b!c!.\frac{(a+b+c)!}{a!b!c!}. This is a first appearance of the multinomial idea, which will return in a later lecture.

A Geometric Bijection: Parallelograms in a Triangular Grid

The Bijection Principle becomes especially powerful when a problem looks geometric. In this section we shall see how a complicated-looking family of parallelograms in a triangular grid can be counted by choosing four points on a line.

Definition 3.1

Triangular Subdivision

For n∈ℕn\in\mathbb N, the nnth subdivision of an equilateral triangle ABCABC is obtained as follows:

  1. each side of △ABC\triangle ABC is divided into n+1n+1 equal parts by placing nn division points on it;

  2. through these division points we draw line segments parallel to the three sides of the triangle.

The result is a triangular grid.

For n=1,2,3n=1,2,3, the subdivisions look as follows. The three different colours show the three different directions of the grid lines.

We shall count a certain family of parallelograms in such a grid. There are three possible orientations for such parallelograms, because the triangular grid itself has three directions. We first count the parallelograms of one fixed orientation and then multiply by 33.

Example 3.7

Parallelograms and Four Points on a Line

In the nnth subdivision of △ABC\triangle ABC, let g(n)g(n) denote the total number of parallelograms of the following type, taken over all three orientations of the triangular grid. Prove that g(n)=3(n+34).g(n)=3\binom{n+3}{4}.

Solution.
Tools to recall.

Theorem 2.4 (Bijection Principle)

At first sight, the parallelograms inside the triangular grid are not easy to count one by one. The key idea is to enlarge the triangle and then encode each parallelogram by four points on one base line.

Extend the sides ABAB and ACAC beyond BB and CC to points B′B' and C′C'. We do this so that the nnth subdivision of △ABC\triangle ABC sits naturally inside a larger triangular subdivision of △AB′C′\triangle AB'C'.

I want you to notice the following important point:

on the extended base B′C′B'C' there are exactly n+3n+3 relevant subdivision points.

The picture below shows the idea. The original triangle ABCABC is inside the larger triangle AB′C′AB'C', and the chosen points on B′C′B'C' are highlighted.

Now focus on only one orientation of these parallelograms. We shall describe the two sets being matched.

Set A: parallelograms of this fixed orientation in the nnth subdivision of △ABC\triangle ABC.

Set B: four-element subsets of the n+3n+3 subdivision points on B′C′B'C'.

The geometric construction gives the correspondence: one parallelogram↔four selected points on B′C′.\text{one parallelogram} \quad\longleftrightarrow\quad \text{four selected points on }B'C'. Each parallelogram determines exactly four base points. Conversely, once the four base points are chosen, the grid lines through those points determine exactly one parallelogram of the fixed orientation.

Thus Set A and Set B are in bijection. Therefore the number of parallelograms of one fixed orientation is (n+34).\binom{n+3}{4}. Since the triangular grid has three possible orientations for such parallelograms, the total number is g(n)=3(n+34).g(n)=3\binom{n+3}{4}. Hence, g(n)=3(n+34).\boxed{g(n)=3\binom{n+3}{4}}.

Remark

This example is important because the original objects are geometric and not easy to list. The bijection changes the question into a familiar selection problem: choose 44 points from n+3n+3 points. This is exactly the strength of the Bijection Principle.

Stars and Bars as a Bijection

We now study a very useful application of the Bijection Principle. It is called the Stars and Bars method.

The basic problem is:

How many ways are there to distribute identical objects into distinct boxes?

For example, suppose 77 identical balls are to be distributed among 44 distinct boxes. If the numbers of balls in the four boxes are x1,x2,x3,x4,x_1,x_2,x_3,x_4, then we need x1+x2+x3+x4=7,x_1+x_2+x_3+x_4=7, where each xix_i is a non-negative integer.

Theorem 3.4

Stars and Bars

The number of non-negative integer solutions of x1+x2+⋯+xr=nx_1+x_2+\cdots+x_r=n is (n+r−1r−1).\binom{n+r-1}{r-1}. Equivalently, it is the number of ways to distribute nn identical objects among rr distinct boxes.

Proof.

Represent the nn identical objects by nn stars: ***⋯*⏟n stars.\underbrace{*\ *\ *\ \cdots\ *}_{n\text{ stars}}. To divide these stars into rr boxes, we place r−1r-1 bars among them. The bars separate the boxes.

For example, **|***||****\,|\,***\,|\,\,|\,** represents x1=2,x2=3,x3=0,x4=2.x_1=2, \qquad x_2=3, \qquad x_3=0, \qquad x_4=2. Here there are 77 stars and 33 bars, so this is one distribution of 77 identical objects among 44 distinct boxes.

The picture below shows the same idea visually.

Now we describe the bijection.

Set A: non-negative integer solutions of x1+x2+⋯+xr=n.x_1+x_2+\cdots+x_r=n.

Set B: arrangements of nn stars and r−1r-1 bars in a row.

Given a solution (x1,x2,…,xr)(x_1,x_2,\ldots,x_r), write x1x_1 stars, then a bar, then x2x_2 stars, then a bar, and so on. This produces exactly one stars-and-bars arrangement. Conversely, every stars-and-bars arrangement tells us how many stars are in each box, so it gives exactly one solution.

Thus Set A and Set B are in bijection.

There are n+(r−1)=n+r−1n+(r-1)=n+r-1 total symbols, and we only need to choose the positions of the r−1r-1 bars. Hence the number of arrangements is (n+r−1r−1).\binom{n+r-1}{r-1}. This proves the theorem.

Example 3.8

Non-negative Solutions

Find the number of non-negative integer solutions of x1+x2+x3+x4=6.x_1+x_2+x_3+x_4=6.

Solution.

Here n=6n=6 and r=4r=4. By Theorem 3.4 (Stars and Bars), the number of solutions is (6+4−14−1)=(93)=84.\binom{6+4-1}{4-1}=\binom{9}{3}=84. Hence the answer is 84.\boxed{84}.

Example 3.9

Identical Balls into Distinct Boxes

In how many ways can 88 identical balls be distributed among 33 distinct boxes?

Solution.

Let xix_i denote the number of balls in the ii-th box. Then we need x1+x2+x3=8,x_1+x_2+x_3=8, where x1,x2,x3≥0x_1,x_2,x_3\ge 0. By Theorem 3.4 (Stars and Bars), the number of ways is (8+3−13−1)=(102)=45.\binom{8+3-1}{3-1}=\binom{10}{2}=45. Thus, the answer is 45.\boxed{45}.

Theorem 3.5

Positive Stars and Bars

The number of positive integer solutions of x1+x2+⋯+xr=nx_1+x_2+\cdots+x_r=n is (n−1r−1).\binom{n-1}{r-1}.

Proof.

If all xix_i are positive, first give 11 object to each of the rr boxes. This uses rr objects. We are left with n−rn-r objects to distribute freely among the rr boxes.

So the number of positive solutions is the number of non-negative solutions of y1+y2+⋯+yr=n−r,y_1+y_2+\cdots+y_r=n-r, which is ((n−r)+r−1r−1)=(n−1r−1).\binom{(n-r)+r-1}{r-1}=\binom{n-1}{r-1}.

Example 3.10

Find the number of positive integer solutions of x1+x2+x3=10.x_1+x_2+x_3=10.

Solution.

Here n=10n=10 and r=3r=3. By Theorem 3.5 (Positive Stars and Bars), the number of solutions is (10−13−1)=(92)=36.\binom{10-1}{3-1}=\binom{9}{2}=36. Hence the answer is 36.\boxed{36}.

Find the number of non-negative integer solutions of x1+x2+x3=15x_1+x_2+x_3=15 with x1≥2,x2≥3,x3≥1.x_1\ge 2, \qquad x_2\ge 3, \qquad x_3\ge 1.

The Complement Method

The complement method is used when a condition is difficult to count directly, but its opposite is easy to count.

The key phrases are: at least one,not all,none,avoid.\text{at least one}, \qquad \text{not all}, \qquad \text{none}, \qquad \text{avoid}.

We already stated the Theorem 2.10 (Principle of Complementation) in Lecture 2. In practice, it says: required count=total count−bad count.\boxed{\text{required count} = \text{total count} - \text{bad count}.}

Example 3.12

At least one die shows five

Three distinct dice are rolled. Find the number of outcomes in which at least one die shows 55.

Solution.

Since the dice are distinct, the total number of outcomes is 63.6^3. We want at least one die to show 55. Instead of counting this directly, count the opposite event.

The opposite event is: no die shows 5.\text{no die shows }5. If no die shows 55, each die has only 55 choices: 1,2,3,4,6.1,2,3,4,6. So the number of outcomes with no 55 is 53.5^3. Therefore, by the Theorem 2.10 (Principle of Complementation), the number of outcomes with at least one 55 is 63−53=216−125=91.6^3-5^3=216-125=91. Hence, the answer is 91.\boxed{91}.

How many five-digit telephone numbers have at least one repeated digit? Assume that a telephone number may begin with 00.

Solution.

The total number of five-digit telephone numbers is 105.10^5. We need at least one repeated digit. The opposite condition is: all five digits are distinct.\text{all five digits are distinct}. The number of telephone numbers with all digits distinct is 10⋅9⋅8⋅7⋅6.10\cdot 9\cdot 8\cdot 7\cdot 6. Therefore, by the complement method, the required number is 105−10⋅9⋅8⋅7⋅6.10^5-10\cdot 9\cdot 8\cdot 7\cdot 6. Thus, 100000−30240=69760.100000-30240=69760. Hence, the answer is 69760.\boxed{69760}.

The total number of selections of 44 letters from 2626 letters is (264).\binom{26}{4}. The opposite of “at least one vowel” is “no vowel”. That means all 44 letters are consonants. This can be done in (214)\binom{21}{4} ways.

Choosing Numbers with No Two Consecutive

Example 3.15

Subsets with a Neighbouring Pair

Let [n]={1,2,…,n}.[n]=\{1,2,\ldots,n\}. How many rr-element subsets of [n][n] contain at least one pair of consecutive integers?

Solution.

For example, the subset {2,5,6,10}\{2,5,6,10\} contains a neighbouring pair, because 55 and 66 are consecutive. On the other hand, {2,5,8,11}\{2,5,8,11\} contains no neighbouring pair.

Direct counting is not convenient here. A subset may contain more than one neighbouring pair. For instance, {3,4,5,9}\{3,4,5,9\} contains both {3,4}\{3,4\} and {4,5}\{4,5\}. Therefore, instead of trying to count such subsets directly, we use the complement method.

The total number of rr-element subsets of [n][n] is (nr).\binom{n}{r}. So it remains to count the opposite case: no two selected elements are consecutive.\text{no two selected elements are consecutive.}

The gap bijection. Represent an unchosen element by a blue ball and a chosen element by an orange ball. Since rr elements are chosen, the number of unchosen elements is n−r.n-r. If these n−rn-r unchosen elements are placed in a row, they create exactly n−r+1n-r+1 gaps: one before the first unchosen element, one after the last unchosen element, and one between every two consecutive unchosen elements.

To ensure that no two chosen elements are consecutive, we may put at most one chosen element in each gap. Therefore, choosing rr non-neighbouring elements is equivalent to choosing rr gaps from the n−r+1n-r+1 available gaps.

In the diagram, the eight blue balls represent the n−r=8n-r=8 unchosen elements. They create nine gaps. We choose four of those gaps and place one orange ball in each chosen gap. This produces the subset {2,5,9,12}.\{2,5,9,12\}. Notice that no two selected numbers are consecutive.

Why is this a bijection? Start with an rr-element subset in which no two selected elements are consecutive. After removing the selected elements, the remaining n−rn-r unchosen elements appear in a fixed row. Every selected element occupies exactly one of the n−r+1n-r+1 gaps. Since no two selected elements are consecutive, no gap contains more than one selected element. Thus every non-neighbouring subset gives a unique choice of rr gaps.

Conversely, choose any rr of the n−r+1n-r+1 gaps and place one selected element in each chosen gap. Then two selected elements cannot become consecutive, because between two selected internal gaps there is at least one unchosen element. Hence every choice of rr gaps gives exactly one rr-subset with no neighbouring pair.

Therefore, by the Theorem 3.1 (Bijection Principle, Revisited), Nno consecutive=(n−r+1r).N_{\text{no consecutive}} = \binom{n-r+1}{r}.

Now we use the complement method: Nneighbouring pair=(nr)−(n−r+1r).\boxed{ N_{\text{neighbouring pair}} = \binom{n}{r}-\binom{n-r+1}{r} }. We use the convention that (mr)=0whenever m<r.\binom{m}{r}=0 \qquad\text{whenever }m<r. ⚠ Common mistake

Do not use the complement method unless you have correctly identified the total set and the exact opposite condition. For example, the opposite of “at least one” is “none”, not “exactly one”.

Why Simple Addition Fails When Cases Overlap

The Addition Principle works only when cases are disjoint. If the cases overlap, simple addition counts the common part more than once.

Suppose AA and BB are two finite sets. If we add |A|+|B||A|+|B|, then the elements in A∩BA\cap B are counted twice. To fix this, we subtract |A∩B||A\cap B| once.

Theorem 3.6

Principle of Inclusion and Exclusion for Two Sets

For finite sets AA and BB, |A∪B|=|A|+|B|−|A∩B|.|A\cup B|=|A|+|B|-|A\cap B|.

Inclusion-Exclusion for Three Sets

When three sets overlap, we must be even more careful. If we add |A|+|B|+|C||A|+|B|+|C|, then pairwise intersections are counted too much. After subtracting pairwise intersections, the triple intersection has been subtracted too much, so we add it back once.

Theorem 3.7

Principle of Inclusion and Exclusion for Three Sets

For finite sets A,B,CA,B,C, |A∪B∪C|=|A|+|B|+|C|−|A∩B|−|B∩C|−|C∩A|+|A∩B∩C|.\begin{aligned} |A\cup B\cup C| ={}& |A|+|B|+|C| \\ &- |A\cap B|-|B\cap C|-|C\cap A| \\ &+ |A\cap B\cap C|. \end{aligned}

Choosing the Counting Method

The following guide is useful.

Phrase in the problemLikely method
“at least one”Count the complement: subtract “none”.
“none” or “not”Often count total minus bad cases.
“A or B” with possible overlapUse inclusion-exclusion.
“A and B both occur”Often use complement or PIE on missing conditions.
Several restrictions to avoidUse inclusion-exclusion if bad cases overlap.

Remark

Inclusion-exclusion is not a replacement for the Addition Principle. It is what we use when the cases overlap. If cases are already disjoint, ordinary addition is enough.

Key Lessons from Lecture 3

Remark

The most important ideas from this lecture are:

  1. A bijection is a clear one-to-one matching between two finite sets. To use it properly, always name the two sets being matched.

  2. Binary strings with exactly rr ones are in bijection with choices of rr positions from nn positions. This is why they are counted by (nr)\binom{n}{r}.

  3. A difficult geometric object can sometimes be counted by matching it with an easier selection problem. In the triangular-subdivision example, parallelograms of one fixed orientation are matched with four chosen points on an extended base line.

  5. The complement method is useful when the phrase “at least one” appears. Count all possibilities and subtract the opposite case.
