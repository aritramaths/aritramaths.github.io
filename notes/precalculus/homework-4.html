§ Day 4 instructions

Problems 1–5 form the symmetry sitting, and Problems 6–10 form the periodicity sitting. Allow at most 9090 minutes for each sitting. In every parity problem, state the domain before substituting −x-x. In every periodicity problem, prove that the proposed shift preserves both the domain and the value, and distinguish a period from the fundamental period. Open “Show solution” below a problem to read its worked solution.

A. Symmetry Practice

Problems 1–5 explore parity through logarithms, exponentials, floor functions and functional equations. Begin by identifying the domain, then compare f(−x)f(-x) with f(x)f(x) and −f(x)-f(x).

☠ Problem 1

Determine whether each function is even, odd, or neither. Give a reason.

  1. f(x)=log(x+1+x2)f(x)=\log\bigl(x+\sqrt{1+x^2}\bigr).

  2. f(x)=xax+1ax−1f(x)=x\dfrac{a^x+1}{a^x-1}, where a>0a>0, a≠1a\ne1.

  3. f(x)=sinx+cosxf(x)=\sin x+\cos x.

  4. f(x)=x2−|x|f(x)=x^2-\left|x\right|.

  5. f(x)=log1−x1+xf(x)=\log\dfrac{1-x}{1+x}.

  6. On ℝ\{0}\mathbb{R}\setminus\{0\}, f(x)=((sgnx)sgnx)nf(x)=\bigl((\operatorname{sgn}x)^{\operatorname{sgn}x}\bigr)^n, where nn is an odd integer.

  7. f(x)=sgnx+x2f(x)=\operatorname{sgn}x+x^2.

  8. A function satisfies f(x+y)+f(x−y)=2f(x)f(y)f(x+y)+f(x-y)=2f(x)f(y) for all real x,yx,y, and f(0)≠0f(0)\ne0. Determine its parity.

Show solutionHide solution to problem 1

  1. Put f(x)=log(x+1+x2)f(x)=\log(x+\sqrt{1+x^2}). The quantity inside the logarithm is positive for every real xx, because 1+x2>|x|\sqrt{1+x^2}>\left|x\right|. Now f(−x)=log(−x+1+x2)=log((−x+1+x2)(x+1+x2)x+1+x2)=log(1x+1+x2)=−log(x+1+x2)=−f(x).\begin{aligned} f(-x) &=\log(-x+\sqrt{1+x^2})\\ &=\log\left(\frac{(-x+\sqrt{1+x^2})(x+\sqrt{1+x^2})} {x+\sqrt{1+x^2}}\right)\\ &=\log\left(\frac{1}{x+\sqrt{1+x^2}}\right)\\ &=-\log(x+\sqrt{1+x^2})=-f(x). \end{aligned} Thus ff is odd.

  2. Let g(x)=x(ax+1)/(ax−1)g(x)=x(a^x+1)/(a^x-1). Its domain is ℝ\{0}\mathbb{R}\setminus\{0\}, which is symmetric. Then g(−x)=−xa−x+1a−x−1=−x1+ax1−ax=xax+1ax−1=g(x).\begin{aligned} g(-x) &=-x\frac{a^{-x}+1}{a^{-x}-1} =-x\frac{1+a^x}{1-a^x} =x\frac{a^x+1}{a^x-1}=g(x). \end{aligned} Hence gg is even.

  3. f(−x)=−sinx+cosx,f(-x)=-\sin x+\cos x, which is neither f(x)=sinx+cosxf(x)=\sin x+\cos x nor −f(x)-f(x) for all xx. Therefore the function is neither.

  4. Since (−x)2=x2(-x)^2=x^2 and |−x|=|x|\left|-x\right|=\left|x\right|, f(−x)=x2−|x|=f(x).f(-x)=x^2-\left|x\right|=f(x). The function is even.

  5. The logarithm requires (1−x)/(1+x)>0(1-x)/(1+x)>0, whose solution is −1<x<1-1<x<1, a symmetric domain. On it, f(−x)=log1+x1−x=log(1−x1+x)−1=−f(x).\begin{aligned} f(-x) &=\log\frac{1+x}{1-x} =\log\left(\frac{1-x}{1+x}\right)^{-1} =-f(x). \end{aligned} Thus ff is odd.

  6. For x>0x>0, sgnx=1\operatorname{sgn}x=1, so the value is 11. For x<0x<0, sgnx=−1\operatorname{sgn}x=-1, so ((−1)−1)n=(−1)n=−1((-1)^{-1})^n=(-1)^n=-1 because nn is odd. Thus the function equals sgnx\operatorname{sgn}x on ℝ\{0}\mathbb{R}\setminus\{0\}, and is odd there. The input 00 is excluded because the power would involve the indeterminate expression 000^0.

  7. At x=1x=1, f(1)=2f(1)=2, while f(−1)=0f(-1)=0. These are neither equal nor negatives, so the function is neither.

  8. First set x=y=0x=y=0: 2f(0)=2f(0)2.2f(0)=2f(0)^2. Since f(0)≠0f(0)\ne0, division gives f(0)=1f(0)=1. Next put x=0x=0 and leave yy arbitrary: f(y)+f(−y)=2f(0)f(y)=2f(y).f(y)+f(-y)=2f(0)f(y)=2f(y). Subtracting f(y)f(y) gives f(−y)=f(y)f(-y)=f(y). Hence ff is even.

Determine whether f(x)=(−1)⌊x⌋f(x)=(-1)^{\lfloor x\rfloor} is even, odd, or neither.

Show solutionHide solution to problem 2

The domain is ℝ\mathbb{R}, but one counterexample is enough to reject each parity. Take x=1/2x=1/2. Then f(1/2)=(−1)0=1,f(1/2)=(-1)^0=1, whereas f(−1/2)=(−1)−1=−1.f(-1/2)=(-1)^{-1}=-1. A function is defined for x≥0x\ge0 by f(x)={x|x|,0≤x<1,2x,x≥1.f(x)= \begin{cases} x\left|x\right|,&0\le x<1,\\ 2x,&x\ge1. \end{cases} Write its definition for x≤0x\le0 if (a) ff is even; (b) ff is odd.

☠ Problem 4

Show that f(x)=2x(sinx+tanx)2⌊x+21ππ⌋−41f(x)=\frac{2x(\sin x+\tan x)} {2\left\lfloor\dfrac{x+21\pi}{\pi}\right\rfloor-41} is symmetric about the origin on its natural domain.

Show solutionHide solution to problem 4

Write D(x)=2⌊x+21ππ⌋−41.D(x)=2\left\lfloor\frac{x+21\pi}{\pi}\right\rfloor-41. This denominator is an odd integer and therefore never 00. The natural domain only excludes the points where tangent is undefined: x≠π2+kπ.x\ne\frac\pi2+k\pi. This domain is symmetric about 00.

Let N(x)=2x(sinx+tanx)N(x)=2x(\sin x+\tan x). Then N(−x)=2(−x)(−sinx−tanx)=N(x),N(-x)=2(-x)(-\sin x-\tan x)=N(x), so the numerator is even. If x/π∉ℤx/\pi\notin\mathbb{Z}, ⌊−xπ⌋=−⌊xπ⌋−1,\left\lfloor-\frac{x}{\pi}\right\rfloor =-\left\lfloor\frac{x}{\pi}\right\rfloor-1, and hence D(−x)=2(−⌊xπ⌋−1)+1=−D(x).D(-x)=2\left(-\left\lfloor\frac{x}{\pi}\right\rfloor-1\right)+1 =-D(x). Therefore f(−x)=N(x)/(−D(x))=−f(x)f(-x)=N(x)/(-D(x))=-f(x). If x=nπx=n\pi, both f(x)f(x) and f(−x)f(-x) are 00, so the identity remains true at the exceptional floor endpoints. Thus f is odd\boxed{f\text{ is odd}}, and its graph is symmetric about the origin.

☠ Problem 5

For which real aa is f(x)=⌊x2a⌋sinx+cosx,−20≤x≤20,f(x)=\left\lfloor\frac{x^2}{a}\right\rfloor\sin x+\cos x, \qquad -20\le x\le20, an even function? Assume a≠0a\ne0.

The factor q(x)=⌊x2a⌋q(x)=\left\lfloor\frac{x^2}{a}\right\rfloor is even because it depends on x2x^2. Hence q(x)sinxq(x)\sin x is odd, while cosx\cos x is even. Their sum can be even only if the odd part is identically zero: q(x)sinx=0(−20≤x≤20).q(x)\sin x=0\qquad(-20\le x\le20).

If a>400a>400, then 0≤x2a≤400a<10\le\frac{x^2}{a}\le\frac{400}{a}<1 throughout the interval. Thus q(x)=0q(x)=0 everywhere and f(x)=cosxf(x)=\cos x, an even function.

If 0<a≤4000<a\le400, choose xx sufficiently close to 2020 but not a multiple of π\pi. Then x2/a≥1x^2/a\ge1, so q(x)≠0q(x)\ne0, and sinx≠0\sin x\ne0; the odd part does not vanish. The endpoint a=400a=400 is excluded because q(20)=1q(20)=1 and sin20≠0\sin20\ne0.

B. Periodicity Practice

☠ Problem 6

Find the fundamental period when it exists; otherwise explain why the function is not periodic.

  1. ⌊sin3x⌋+|cos6x|\lfloor\sin3x\rfloor+\left|\cos 6x\right|.

  2. 12(|sinx|cosx+|cosx|sinx)\dfrac12\left(\dfrac{\left|\sin x\right|}{\cos x} +\dfrac{\left|\cos x\right|}{\sin x}\right).

  3. ecos(πx/4)+x−⌊x⌋+cos(πx/2)e^{\cos(\pi x/4)}+x-\lfloor x\rfloor+\cos(\pi x/2).

  4. 3sin(πx/3)+4cos(πx/4)3\sin(\pi x/3)+4\cos(\pi x/4).

  5. cos3x+sin(3πx)\cos3x+\sin(3\pi x).

  6. sin(πx/n!)−cos(πx/(n+1)!)\sin(\pi x/n!)-\cos(\pi x/(n+1)!), where n∈ℕn\in\mathbb{N}.

  7. x−⌊x−b⌋x-\lfloor x-b\rfloor, where b∈ℝb\in\mathbb{R}.

  8. eln(sinx)+tan3x−csc(3x−5)e^{\ln(\sin x)}+\tan^3x-\csc(3x-5), on its natural domain.

Show solutionHide solution to problem 6

  1. The function ⌊sin3x⌋\lfloor\sin3x\rfloor repeats when 3x3x increases by 2π2\pi, so it has period 2π/32\pi/3. The function |cos6x|\left|\cos 6x\right| has period π/6\pi/6. Since 2π/3=4(π/6)2\pi/3=4(\pi/6), the first number is a common period. A shift by π/3\pi/3 reverses the sign of sin3x\sin3x and changes its floor, so the graph does not repeat halfway. Hence T=2π3.\boxed{T=\frac{2\pi}{3}}.

  2. The natural domain excludes every multiple of π/2\pi/2. A shift by π\pi changes both denominators' signs but leaves both absolute-value numerators unchanged. Therefore f(x+π)=−f(x).f(x+\pi)=-f(x). Thus π\pi is an anti-period and 2π2\pi is a period. It is not shortened to π/2\pi/2, since f(π/4)=1,f(3π/4)=0.f(\pi/4)=1, \qquad f(3\pi/4)=0. The sign pattern on the four quadrants then rules out any smaller repeat, so T=2π\boxed{T=2\pi}.

  3. The three component periods are 8,1,4,8,\qquad 1,\qquad 4, respectively. Therefore 88 is a common period. The fractional-part term creates jumps at the integers, so any period must be an integer. A shift by 44 changes ecos(πx/4)e^{\cos(\pi x/4)} to e−cos(πx/4)e^{-\cos(\pi x/4)}, which is not generally equal to it. Hence no proper integer divisor of 88 repeats the graph, and T=8\boxed{T=8}.

  4. The periods of the two terms are 2ππ/3=6,2ππ/4=8.\frac{2\pi}{\pi/3}=6, \qquad \frac{2\pi}{\pi/4}=8. Their least common multiple is 2424. Since the two nonzero frequencies are different, no cancellation removes the final oscillation, so T=24\boxed{T=24}.

  5. The component periods are 2π/32\pi/3 and 2/32/3. Their ratio is π\pi, which is irrational, so no positive common period exists. To justify that the sum cannot hide this incompatibility, a later Calculus argument differentiates twice: the original sum and its second derivative form two linear equations from which each trigonometric component can be recovered. Any period of the sum would then be a period of each component, an impossibility. Thus the function is not periodic\boxed{\text{not periodic}}.

  6. The sine term has period 2n!2n!, while the cosine term has period 2(n+1)!2(n+1)!. Since 2(n+1)!=2(n+1)n!2(n+1)!=2(n+1)n! is an integer multiple of 2n!2n!, it is a common period. The final cosine term prevents a smaller common repeat, so T=2(n+1)!.\boxed{T=2(n+1)!}.

  7. Put u=x−bu=x-b. Since x=u+bx=u+b, x−⌊x−b⌋=u+b−⌊u⌋={u}+b={x−b}+b.x-\lfloor x-b\rfloor =u+b-\lfloor u\rfloor =\{u\}+b =\{x-b\}+b. The fractional part has fundamental period 11, and the vertical shift by bb does not change it. Therefore T=1\boxed{T=1}.

  8. The identity eln(sinx)=sinxe^{\ln(\sin x)}=\sin x is legal only when sinx>0\sin x>0. The natural domain also excludes zeros of cosx\cos x and zeros of sin(3x−5)\sin(3x-5). All three domain conditions, and all three values, repeat after 2π2\pi. A shift by π\pi does not preserve the condition sinx>0\sin x>0, so it cannot be a period of the original function. Hence T=2π.\boxed{T=2\pi}.

☠ Problem 7

A real-valued function satisfies f(x)+f(x+4)=f(x+2)+f(x+6)for every x∈ℝ.f(x)+f(x+4)=f(x+2)+f(x+6) \qquad\text{for every }x\in\mathbb{R}. Prove that 88 is a period. Must 88 be the fundamental period?

Show solutionHide solution to problem 7

Define the two-step difference d(x)=f(x+2)−f(x).d(x)=f(x+2)-f(x). The given equation can be rearranged as f(x+6)−f(x+4)=f(x)−f(x+2)=−d(x).f(x+6)-f(x+4)=f(x)-f(x+2)=-d(x). The left side is d(x+4)d(x+4), so d(x+4)=−d(x).d(x+4)=-d(x). Now telescope over four two-unit steps: f(x+8)−f(x)=[f(x+2)−f(x)]+[f(x+4)−f(x+2)]+[f(x+6)−f(x+4)]+[f(x+8)−f(x+6)]=d(x)+d(x+2)+d(x+4)+d(x+6).\begin{aligned} f(x+8)-f(x) &=[f(x+2)-f(x)]+[f(x+4)-f(x+2)]\\ &\quad+[f(x+6)-f(x+4)]+[f(x+8)-f(x+6)]\\ &=d(x)+d(x+2)+d(x+4)+d(x+6). \end{aligned} But d(x+4)=−d(x),d(x+6)=−d(x+2),d(x+4)=-d(x),\qquad d(x+6)=-d(x+2), so the four terms cancel and f(x+8)=f(x)f(x+8)=f(x). Thus 88 is a period.

It need not be fundamental. A constant function satisfies the equation and has no fundamental period, while f(x)=sin(πx)f(x)=\sin(\pi x) satisfies the equation and has fundamental period 22. Therefore 8 is always a period, but need not be fundamental.\boxed{8\text{ is always a period, but need not be fundamental}.}

☠ Problem 8

Examine the claim that every real-valued solution of f(x+λ)=1+2f(x)−f(x)2f(x+\lambda)=1+2f(x)-f(x)^2 must be periodic. Explain exactly what can and cannot be concluded from the given recurrence.

Show solutionHide solution to problem 8

Let u(x)=f(x)−1u(x)=f(x)-1. Then u(x+λ)=f(x+λ)−1=2f(x)−f(x)2=1−(f(x)−1)2=1−u(x)2.\begin{aligned} u(x+\lambda) &=f(x+\lambda)-1\\ &=2f(x)-f(x)^2\\ &=1-(f(x)-1)^2=1-u(x)^2. \end{aligned} Applying this rule twice gives u(x+2λ)=1−(1−u(x)2)2,u(x+2\lambda)=1-(1-u(x)^2)^2, which is not identically equal to u(x)u(x). Thus no two-step period follows. Nor does the recurrence by itself force some longer common period.

For a concrete non-periodic orbit, start with u0=1/2u_0=1/2 and define un+1=1−un2.u_{n+1}=1-u_n^2. The first values are 12,34,716,207256,…\frac12,\quad\frac34,\quad\frac7{16},\quad\frac{207}{256},\ldots If un=a/2mu_n=a/2^m in lowest terms with aa odd, then un+1=22m−a222m,u_{n+1}=\frac{2^{2m}-a^2}{2^{2m}}, whose numerator is odd. Hence the power of 22 in the denominator doubles at every step, so this forward orbit never returns to 1/21/2. Backward terms can be chosen recursively by un−1=1−unu_{n-1}=\sqrt{1-u_n}. Placing this bi-infinite orbit on one set x0+nλx_0+n\lambda, and fixed-point orbits on the other residue classes modulo λ\lambda, constructs a real-valued solution with no period. Therefore periodicity is not implied by the stated recurrence.\boxed{\text{periodicity is not implied by the stated recurrence}.} Some special solutions, such as constant fixed points, are periodic; the claim fails because it says every solution must be periodic.

☠ Problem 9

Let p>0p>0 and suppose f(x+p)=1+2−3f(x)+3f(x)2−f(x)33f(x+p)=1+\sqrt[3]{2-3f(x)+3f(x)^2-f(x)^3} for every real xx. Prove that 2p2p is a period of ff.

Show solutionHide solution to problem 9

Put u(x)=f(x)−1u(x)=f(x)-1, so f(x)=1+u(x)f(x)=1+u(x). ☠ Problem 10

Suppose f(x−1)+f(x+1)=3f(x)f(x-1)+f(x+1)=3f(x) for every real xx, and f(5)=100f(5)=100. Is ∑r=099f(5+12r)\sum_{r=0}^{99}f(5+12r) uniquely determined? Give a rigorous reason.

Show solutionHide solution to problem 10

At the integer inputs, write un=f(n)u_n=f(n). The equation becomes un+1=3un−un−1u_{n+1}=3u_n-u_{n-1}. A second-order recurrence needs two consecutive values. We know only u5=100u_5=100; the value u6u_6 is free. Once u6u_6 is chosen, the recurrence determines all later and earlier integer values, but different choices give different sequences.

To see that the requested sum changes, compare two solutions whose difference wnw_n satisfies the same recurrence with w5=0w_5=0, w6=1w_6=1. Then w7=3w6−w5=3,w8=3w7−w6=8,w_7=3w_6-w_5=3,\qquad w_8=3w_7-w_6=8, The positive values continue to grow: if wn>wn−1≥0w_n>w_{n-1}\ge0, then wn+1=2wn+(wn−wn−1)>wn>0w_{n+1}=2w_n+(w_n-w_{n-1})>w_n>0. Induction starts at w6>w5w_6>w_5. In particular, w17>0w_{17}>0. The difference between the two requested sums contains w5+w17+w29+⋯,w_5+w_{17}+w_{29}+\cdots, which is not zero. The functional equation on all real inputs can be extended independently on each residue class modulo 11, so these integer sequences belong to genuine real-valued solutions. Hence ∑r=099f(5+12r) is not uniquely determined.\boxed{\sum_{r=0}^{99}f(5+12r)\text{ is not uniquely determined}.} An additional value such as f(6)f(6), or an independent condition, would be needed.

💡 Day 4 proof checklist

  • Write the natural domain first.

  • Check whether the domain is symmetric about 00.

  • Compute f(−x)f(-x) before deciding the parity.

  • For a proposed period TT, check the domain as well as f(x+T)=f(x)f(x+T)=f(x).

  • A proposed number may be a period without being the least positive period.

  • Preserve holes and excluded endpoints after simplifying a formula.
