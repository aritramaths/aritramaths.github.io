A. Function Language and Graphs

☠ Problem 1

Let A={1,2,3,4}A=\left\{1,2,3,4\right\}, B={p,q,r}B=\left\{p,q,r\right\}, and f(1)=p,f(2)=q,f(3)=q,f(4)=p.f(1)=p,\quad f(2)=q,\quad f(3)=q,\quad f(4)=p. State the domain, codomain and range.

Show solutionHide solution to problem 1

The function has been declared from AA to BB, so Domain(f)=A={1,2,3,4}\operatorname{Domain}(f)=A=\left\{1,2,3,4\right\} and Codomain(f)=B={p,q,r}.\operatorname{Codomain}(f)=B=\left\{p,q,r\right\}. The values actually attained are pp and qq; the element rr is not used. Hence Range(f)={p,q}.\boxed{\operatorname{Range}(f)=\left\{p,q\right\}}. Notice that f(2)=f(3)=qf(2)=f(3)=q is allowed: two inputs may share an output.

☠ Problem 2

Which of the following assignments defines a function A→BA\to B?

  1. every input has exactly one image;

  2. one input has two different images;

  3. one input has no image;

  4. every output must be used exactly once.

Show solutionHide solution to problem 2

A function must assign exactly one image to every input. Therefore option aa is the defining condition.

Option bb fails because one input receives two outputs. Option cc fails because one input receives no output. Option dd is not required: some codomain elements may remain unused and different inputs may share an output. Thus (a).\boxed{\text{(a)}}.

☠ Problem 3

If |A|=6\left|A\right|=6 and |B|=4\left|B\right|=4, how many functions A→BA\to B are there?

Show solutionHide solution to problem 3

Each of the six elements of AA may independently choose any one of the four elements of BB as its image. Therefore the number of functions is 4⋅4⋅4⋅4⋅4⋅4⏟6 choices=46.\underbrace{4\cdot4\cdot4\cdot4\cdot4\cdot4}_{6\text{ choices}} =4^6. Hence 46=4096.\boxed{4^6=4096}.

Show solutionHide solution to problem 4

For y=x3−xy=x^3-x, every real xx gives exactly one real value of yy, so its graph passes the vertical-line test.

The circle x2+y2=4x^2+y^2=4 gives y=±4−x2.y=\pm\sqrt{4-x^2}. For every −2<x<2-2<x<2, a vertical line meets the circle once above and once below the xx-axis. Thus the complete circle is not the graph of one function of xx.

Finally, y=4−x2y=\sqrt{4-x^2} is the upper semicircle. For each x∈[−2,2]x\in[-2,2], the non-negative square root gives exactly one output. Hence it passes the test. Therefore y=x3−xandy=4−x2are functions of x;x2+y2=4is not.\boxed{y=x^3-x\ \text{and}\ y=\sqrt{4-x^2}\ \text{are functions of }x; \quad x^2+y^2=4\ \text{is not}.}

B. Algebraic Domain Problems

For Problems 5–9, determine the real domain.

☠ Problem 5

f(x)=2x−1.f(x)=\sqrt{2x-1}.

Show solutionHide solution to problem 5

The square root is real when 2x−1≥0.2x-1\ge0. Solving gives x≥1/2x\ge1/2. The endpoint is included because a zero radicand is allowed. Thus Df=[1/2,∞).\boxed{D_f=[1/2,\infty)}.

☠ Problem 6

f(x)=x−1+6−x.f(x)=\sqrt{x-1}+\sqrt{6-x}.

Show solutionHide solution to problem 6

Both radicals must be real: x−1≥0,6−x≥0.x-1\ge0, \qquad 6-x\ge0. Equivalently, x≥1x\ge1 and x≤6x\le6. Both conditions must hold for the same input, so we take their intersection: Df=[1,6].\boxed{D_f=[1,6]}.

☠ Problem 7

f(x)=x2−x−2+13+2x−x2.f(x)=\sqrt{x^2-x-2}+\frac1{\sqrt{3+2x-x^2}}.

Show solutionHide solution to problem 7

The first square root requires x2−x−2=(x−2)(x+1)≥0.x^2-x-2=(x-2)(x+1)\ge0. Its solution is x∈(−∞,−1]∪[2,∞).x\in(-\infty,-1]\cup[2,\infty). The second square root occurs in a denominator, so its radicand must be strictly positive: 3+2x−x2>0⇔x2−2x−3<0⇔(x−3)(x+1)<0.\begin{aligned} 3+2x-x^2&>0\\ \Longleftrightarrow\quad x^2-2x-3&<0\\ \Longleftrightarrow\quad (x-3)(x+1)&<0. \end{aligned} Hence −1<x<3-1<x<3. Intersecting the two admissible sets, ((−∞,−1]∪[2,∞))∩(−1,3)=[2,3).\bigl((-\infty,-1]\cup[2,\infty)\bigr)\cap(-1,3)=[2,3). Therefore Df=[2,3).\boxed{D_f=[2,3)}. At x=2x=2 the first radicand may vanish, so 22 is included. At x=3x=3 the denominator vanishes, so 33 is excluded.

☠ Problem 8

f(x)=xx2−x−2.f(x)=\frac{x}{\sqrt{x^2-x-2}}.

Show solutionHide solution to problem 8

Because the radical is in the denominator, we need x2−x−2>0.x^2-x-2>0. Factoring, (x−2)(x+1)>0.(x-2)(x+1)>0. The product is positive outside the roots −1-1 and 22, so Df=(−∞,−1)∪(2,∞).\boxed{D_f=(-\infty,-1)\cup(2,\infty)}. Both roots are excluded because they make the denominator zero.

☠ Problem 9

f(x)=x−1x+2.f(x)=\sqrt{\frac{x-1}{x+2}}.

Show solutionHide solution to problem 9

The radical requires x−1x+2≥0,x≠−2.\frac{x-1}{x+2}\ge0, \qquad x\ne-2. The critical points are −2-2, where the expression is undefined, and 11, where it is zero. The signs are x(−∞,−2)−2(−2,1)1(1,∞)(x−1)/(x+2)+undefined−0+\begin{array}{c|ccccc} x&(-\infty,-2)&-2&(-2,1)&1&(1,\infty)\\ \hline (x-1)/(x+2)&+&\text{undefined}&-&0&+ \end{array} Therefore Df=(−∞,−2)∪[1,∞).\boxed{D_f=(-\infty,-2)\cup[1,\infty)}. The zero at x=1x=1 is permitted; the denominator zero at x=−2x=-2 never is.

C. Range and Trigonometric Problems

☠ Problem 10

Find the range of f(x)=x−1+5−x.f(x)=\sqrt{x-1}+\sqrt{5-x}.

Show solutionHide solution to problem 10

The domain is [1,5][1,5]. Set a=x−1,b=5−x.a=\sqrt{x-1},\qquad b=\sqrt{5-x}. Then a,b≥0a,b\ge0, f(x)=a+bf(x)=a+b, and a2+b2=4.a^2+b^2=4. First, (a+b)2=a2+b2+2ab≥4,(a+b)^2=a^2+b^2+2ab\ge4, so f(x)≥2f(x)\ge2. Equality occurs at x=1x=1 or x=5x=5.

Next, (a−b)2≥0(a-b)^2\ge0 gives a2+b2≥2aba^2+b^2\ge2ab, so 2ab≤42ab\le4. Thus (a+b)2=4+2ab≤8,(a+b)^2=4+2ab\le8, and f(x)≤22f(x)\le2\sqrt2. Equality requires a=ba=b, which occurs at x=3x=3. Every output between these bounds has an admissible input, as constructed explicitly in the lecture's radical-sum example. Therefore Range(f)=[2,22].\boxed{\operatorname{Range}(f)=[2,2\sqrt2]}.

☠ Problem 11

Find the range of f(x)=x1+x2.f(x)=\frac{x}{1+x^2}.

Show solutionHide solution to problem 11

The denominator 1+x21+x^2 is positive for every real xx, so Df=ℝD_f=\mathbb{R}. Put y=x1+x2.y=\frac{x}{1+x^2}. Then yx2−x+y=0.yx^2-x+y=0. For this quadratic equation to have a real solution xx, its discriminant must satisfy Δ=(−1)2−4y2=1−4y2≥0.\Delta=(-1)^2-4y^2=1-4y^2\ge0. Hence −12≤y≤12.-\frac12\le y\le\frac12. At y=1/2y=1/2 the equation is (x−1)2=0(x-1)^2=0, and at y=−1/2y=-1/2 it is (x+1)2=0(x+1)^2=0. Thus both endpoints occur. Therefore Range(f)=[−12,12].\boxed{\operatorname{Range}(f)=\left[-\frac12,\frac12\right]}.

☠ Problem 12

Find the range of f(x)=sinx+cosx+3.f(x)=\sin x+\cos x+3.

Show solutionHide solution to problem 12

We write sinx+cosx=2(12sinx+12cosx).\sin x+\cos x =\sqrt2\left(\frac1{\sqrt2}\sin x+ \frac1{\sqrt2}\cos x\right). Since 12=sinπ4=cosπ4,\frac1{\sqrt2}=\sin\frac\pi4=\cos\frac\pi4, the cosine subtraction formula gives sinx+cosx=2cos(x−π4).\sin x+\cos x=\sqrt2\cos\left(x-\frac\pi4\right). Thus −2≤sinx+cosx≤2.-\sqrt2\le\sin x+\cos x\le\sqrt2. Adding 33, 3−2≤f(x)≤3+2.3-\sqrt2\le f(x)\le3+\sqrt2. Both endpoints occur because cosine attains −1-1 and 11. Hence Range(f)=[3−2,3+2].\boxed{\operatorname{Range}(f)=[3-\sqrt2,3+\sqrt2]}.

☠ Problem 13

Find the domain and range of f(x)=sinx−1.f(x)=\sqrt{\sin x-1}.

Show solutionHide solution to problem 13

The square root requires sinx−1≥0,\sin x-1\ge0, or sinx≥1\sin x\ge1. But sinx≤1\sin x\le1 for all real xx, so equality is forced: sinx=1.\sin x=1. This occurs exactly when x=π2+2kπ,k∈ℤ.x=\frac\pi2+2k\pi, \qquad k\in\mathbb{Z}. At every such input, f(x)=0=0f(x)=\sqrt0=0. Therefore Df={π2+2kπ:k∈ℤ},Range(f)={0}.\boxed{D_f=\left\{\frac\pi 2+2k\pi:k\in\mathbb{Z}\right\}, \qquad \operatorname{Range}(f)=\left\{0\right\}}.

D. Exponential and Logarithmic Problems

☠ Problem 14

Evaluate 2−3,log218,log327.2^{-3},\qquad \log_2\frac18,\qquad \log_3 27.

Show solutionHide solution to problem 14

Using the laws of exponents, 2−3=123=18.2^{-3}=\frac1{2^3}=\frac18. A logarithm asks for an exponent. Since 2−3=1/82^{-3}=1/8, log218=−3.\log_2\frac18=-3. Since 33=273^3=27, log327=3.\log_3 27=3. Thus 2−3=18,log218=−3,log327=3.\boxed{2^{-3}=\frac18,\qquad \log_2\frac18=-3,\qquad \log_3 27=3}.

☠ Problem 15

Determine the domain of f(x)=log2(x−1).f(x)=\log_2(x-1).

Show solutionHide solution to problem 15

The argument of a real logarithm must be strictly positive. Therefore x−1>0⇔x>1.x-1>0 \quad\Longleftrightarrow\quad x>1. Hence Df=(1,∞).\boxed{D_f=(1,\infty)}. The endpoint x=1x=1 is excluded because log20\log_2 0 is not defined.

☠ Problem 16

Determine the domain of f(x)=log2x.f(x)=\sqrt{\log_2x}.

Show solutionHide solution to problem 16

The outer square root requires log2x≥0.\log_2x\ge0. Because the base 2>12>1, the logarithm is increasing, and log2x≥0⇔x≥20=1.\log_2x\ge0 \quad\Longleftrightarrow\quad x\ge2^0=1. This already implies the basic logarithmic restriction x>0x>0. Therefore Df=[1,∞).\boxed{D_f=[1,\infty)}. At x=1x=1, the logarithm is 00 and the square root is defined.

☠ Problem 17

Find the range of f(x)=2x+1.f(x)=2^x+1.

Show solutionHide solution to problem 17

For every real xx, 2x>0.2^x>0. Hence 2x+1>1,2^x+1>1, so the output 11 is not attained. Conversely, let y>1y>1. Then y−1>0y-1>0, and choosing x=log2(y−1)x=\log_2(y-1) gives 2x=y−12^x=y-1, hence 2x+1=y2^x+1=y. Therefore every y>1y>1 occurs and Range(f)=(1,∞).\boxed{\operatorname{Range}(f)=(1,\infty)}.

☠ Problem 18

Find the domain and range of f(x)=log2(x2+1).f(x)=\log_2(x^2+1).

Show solutionHide solution to problem 18

Since x2+1≥1>0x^2+1\ge1>0 for every real xx, the logarithm is defined for every real input. Thus Df=ℝ.D_f=\mathbb{R}. Also, because the base 2>12>1, log2(x2+1)≥log21=0.\log_2(x^2+1)\ge\log_2 1=0. The lower endpoint 00 occurs at x=0x=0.

Conversely, let y≥0y\ge0. Then 2y≥12^y\ge1, so 2y−1≥02^y-1\ge0. Choose x=2y−1.x=\sqrt{2^y-1}. Then x2+1=2yx^2+1=2^y, and therefore log2(x2+1)=log2(2y)=y.\log_2(x^2+1)=\log_2(2^y)=y. Hence every non-negative output occurs, and Df=ℝ,Range(f)=[0,∞).\boxed{D_f=\mathbb{R}, \qquad \operatorname{Range}(f)=[0,\infty)}.

E. First Glimpse of Reversal

☠ Problem 19

The function f(x)=2xf(x)=2^x produces the outputs 1/4,1,81/4,1,8. Without using a formal inverse-function definition, identify the corresponding inputs and write the answers using logarithmic notation.

Show solutionHide solution to problem 19

We solve each exponential equation by recognising the required exponent: 2x=14=2−2⇒x=−2,2^x=\frac14=2^{-2} \quad\Longrightarrow\quad x=-2, 2x=1=20⇒x=0,2^x=1=2^0 \quad\Longrightarrow\quad x=0, and 2x=8=23⇒x=3.2^x=8=2^3 \quad\Longrightarrow\quad x=3. In logarithmic notation these are log214=−2,log21=0,log28=3.\log_2\frac14=-2, \qquad \log_2 1=0, \qquad \log_2 8=3. Thus the corresponding inputs are −2,0,3.\boxed{-2,\ 0,\ 3}.

☠ Problem 20

Explain why the output 00 does not determine a unique input for f(x)=sinxf(x)=\sin x on ℝ\mathbb{R}. Give three different inputs with output 00, and suggest an interval on which each output occurs at most once. This is a preview question; the formal theory begins in Lecture 3.

Show solutionHide solution to problem 20

The output 00 occurs whenever sinx=0\sin x=0, that is, whenever x=kπx=k\pi for some integer kk. Three examples are sin0=0,sinπ=0,sin2π=0.\sin0=0, \qquad \sin\pi=0, \qquad \sin2\pi=0. Therefore the output 00 does not identify a unique input on the whole real line.

One possible interval on which sine never repeats an output is [−π2,π2].\left[-\frac\pi2,\frac\pi2\right]. On this interval the sine graph strictly rises from −1-1 to 11. Two different inputs therefore have different heights, so a horizontal line meets it at most once. This observation motivates restricting a function before attempting to reverse it. The formal definitions will be given in Lecture 3.
