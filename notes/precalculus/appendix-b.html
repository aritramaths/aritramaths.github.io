B.2 The exponential-logarithm inverse pair

Fix a>0a>0, a≠1a\ne1. The exponential function is Ea(x)=ax.E_a(x)=a^x. Its domain is ℝ\mathbb{R}, and its outputs are always positive, so its range is (0,∞)(0,\infty). It is one-to-one: it is increasing when a>1a>1 and decreasing when 0<a<10<a<1. Therefore it has an inverse function. That inverse is La(x)=logax.L_a(x)=\log_ax.

The domain and range are exchanged by inversion: functiondomainrangeaxℝ(0,∞)logax(0,∞)ℝ\begin{array}{c|c|c} \text{function}&\text{domain}&\text{range}\\ \hline a^x&\mathbb{R}&(0,\infty)\\ \log_ax&(0,\infty)&\mathbb{R} \end{array} and the inverse identities are loga(ax)=x(x∈ℝ),\boxed{\log_a(a^x)=x\quad(x\in\mathbb{R}),} alogax=x(x>0).\boxed{a^{\log_ax}=x\quad(x>0).}

Reflection across y=xy=x

If (u,v)(u,v) lies on y=axy=a^x, then v=auv=a^u. Rewriting gives u=logavu=\log_av, so (v,u)(v,u) lies on y=logaxy=\log_ax. The two points have interchanged coordinates. Therefore the graphs are reflections of each other in the line y=xy=x.

The horizontal asymptote y=0y=0 of axa^x becomes the vertical asymptote x=0x=0 of logax\log_ax. The exponential never reaches 00, so the logarithm never accepts 00.

A complete inequality method

For an inequality involving logarithms:

  1. impose positivity on every logarithm argument;

  2. impose a>0a>0, a≠1a\ne1 if the base contains a variable;

  3. combine logarithms only on that legal domain;

  4. decide whether the base is greater than 11 or between 00 and 11;

  5. remove the logarithm, preserving or reversing the inequality accordingly;

  6. intersect the algebraic answer with the original domain.

Example B.1

Increasing logarithm

Solve log2(x−1)<3\log_2(x-1)<3.

Solution.

First, x−1>0⇒x>1.x-1>0\quad\Longrightarrow\quad x>1. Because 2>12>1, log2x\log_2x is increasing. Therefore log2(x−1)<3⇔x−1<23=8.\log_2(x-1)<3 \quad\Longleftrightarrow\quad x-1<2^3=8. Thus x<9x<9. Intersecting with x>1x>1, x∈(1,9).\boxed{x\in(1,9)}. The left endpoint is excluded because the logarithm would receive argument 00; the right endpoint is excluded because the inequality is strict.

Example B.2

Decreasing logarithm: reverse the inequality

Solve log1/2(2x−1)≥−2.\log_{1/2}(2x-1)\ge-2.

Solution.

The argument condition is 2x−1>0⇒x>12.2x-1>0\quad\Longrightarrow\quad x>\frac12. Because 0<1/2<10<1/2<1, the function log1/2\log_{1/2} is decreasing. Removing the logarithm therefore reverses the order: 2x−1≤(12)−2=4.2x-1\le\left(\frac12\right)^{-2}=4. Hence 2x≤5,x≤52.2x\le5, \qquad x\le\frac52. After intersection with x>1/2x>1/2, x∈(12,52].\boxed{x\in\left(\frac12,\frac52\right]}.

Example B.3

A variable base requires two cases

Solve logx−1(x+3)>1.\log_{x-1}(x+3)>1.

Solution.

The base conditions are x−1>0⇒x>1,x-1>0\quad\Longrightarrow\quad x>1, x−1≠1⇒x≠2.x-1\ne1\quad\Longrightarrow\quad x\ne2. The argument condition x+3>0x+3>0 is automatic once x>1x>1.

Now split according to the base.

Case 1: x−1>1x-1>1, so x>2x>2. The logarithm is increasing, hence x+3>(x−1)1.x+3>(x-1)^1. This reduces to 3>−13>-1, which is always true. Thus every x>2x>2 works.

Case 2: 0<x−1<10<x-1<1, so 1<x<21<x<2. The logarithm is decreasing, so the inequality reverses: x+3<(x−1)1.x+3<(x-1)^1. This would require 3<−13<-1, which is impossible. No value in this case works.

Combining the cases, x∈(2,∞).\boxed{x\in(2,\infty)}.

B.4 Transforming logarithm graphs

The parent graph y=logaxy=\log_ax can be shifted, reflected and stretched using the same graph-transformation rules as any other function.

For y=Aloga(B(x−h))+k,y=A\log_a\bigl(B(x-h)\bigr)+k, the first and most important step is B(x−h)>0.B(x-h)>0. The equation B(x−h)=0B(x-h)=0 gives the vertical asymptote. The outer factor AA stretches vertically and reflects across the xx-axis when A<0A<0; the constant kk shifts vertically.

B.5 Domain problems: every restriction written first

For a real expression logb(x)A(x)\log_{b(x)}A(x), the full checklist is A(x)>0,b(x)>0,b(x)≠1.\boxed{A(x)>0,\qquad b(x)>0,\qquad b(x)\ne1.} Radicals, denominators and outer functions may add further restrictions.

Example B.5

A logarithm under a square root

Find the domain of f(x)=log2(x−1).f(x)=\sqrt{\log_2(x-1)}.

Solution.

The square root requires log2(x−1)≥0.\log_2(x-1)\ge0. Because 2>12>1, the logarithm is increasing, so log2(x−1)≥0⇔x−1≥20=1.\log_2(x-1)\ge0 \quad\Longleftrightarrow\quad x-1\ge2^0=1. Therefore x≥2x\ge2. Notice that this automatically makes the logarithm argument positive. At x=2x=2, the radicand is log21=0\log_21=0, so the endpoint is included. Thus Df=[2,∞).\boxed{D_f=[2,\infty)}.

Example B.6

A logarithm in a denominator

Find the domain of f(x)=1log3(x+2).f(x)=\frac1{\log_3(x+2)}.

Solution.

First the logarithm requires x+2>0⇒x>−2.x+2>0\quad\Longrightarrow\quad x>-2. The denominator must also be nonzero: log3(x+2)≠0.\log_3(x+2)\ne0. Since log31=0\log_31=0, this means x+2≠1⇒x≠−1.x+2\ne1\quad\Longrightarrow\quad x\ne-1. Therefore Df=(−2,−1)∪(−1,∞).\boxed{D_f=(-2,-1)\cup(-1,\infty)}. The point −2-2 is excluded because it gives logarithm argument 00; the point −1-1 is excluded because it makes the whole denominator zero.

Example B.7

The base also depends on xx

Find the domain of f(x)=logx−1(x2−5x+6).f(x)=\log_{x-1}(x^2-5x+6).

Solution.

We impose the three logarithm conditions separately.

Base not equal to 11: x−1≠1⇒x≠2.x-1\ne1\quad\Longrightarrow\quad x\ne2.

Intersect this with x>1x>1: (1,∞)∩((−∞,2)∪(3,∞))=(1,2)∪(3,∞).(1,\infty)\cap\bigl(( -\infty,2)\cup(3,\infty)\bigr) =(1,2)\cup(3,\infty). The condition x≠2x\ne2 is already respected by these open intervals. Hence Df=(1,2)∪(3,∞).\boxed{D_f=(1,2)\cup(3,\infty)}.

Example B.8

A logarithm inside another logarithm

Find the domain of f(x)=log2(log3(x−1)).f(x)=\log_2\bigl(\log_3(x-1)\bigr).

Solution.

The outer logarithm requires its entire argument to be positive: log3(x−1)>0.\log_3(x-1)>0. Because 3>13>1, log3\log_3 is increasing. Therefore log3(x−1)>0⇔x−1>30=1.\log_3(x-1)>0 \quad\Longleftrightarrow\quad x-1>3^0=1. Thus x>2x>2. This condition automatically gives x−1>0x-1>0, so the inner logarithm is defined. Therefore Df=(2,∞).\boxed{D_f=(2,\infty)}. At x=2x=2, the inner logarithm is 00, which the outer logarithm cannot accept.

Example B.9

A decreasing logarithm under a radical

Find the domain of f(x)=log1/2(x−1x+2).f(x)=\sqrt{\log_{1/2}\left(\frac{x-1}{x+2}\right)}.

Solution.

The square root requires log1/2(x−1x+2)≥0.\log_{1/2}\left(\frac{x-1}{x+2}\right)\ge0. Because the base 1/21/2 lies between 00 and 11, the logarithm is decreasing. Hence 0<x−1x+2≤1.0<\frac{x-1}{x+2}\le1. We solve the two requirements.

First, x−1x+2>0\frac{x-1}{x+2}>0 holds when numerator and denominator have the same sign: x<−2orx>1.x<-2\quad\text{or}\quad x>1.

Second, x−1x+2≤1⇔x−1−(x+2)x+2≤0,\frac{x-1}{x+2}\le1 \quad\Longleftrightarrow\quad \frac{x-1-(x+2)}{x+2}\le0, −3x+2≤0.\frac{-3}{x+2}\le0. Since the numerator is negative, the quotient is nonpositive exactly when x+2>0x+2>0, that is, x>−2x>-2.

Intersecting, ((−∞,−2)∪(1,∞))∩(−2,∞)=(1,∞).\bigl(( -\infty,-2)\cup(1,\infty)\bigr)\cap(-2,\infty) =(1,\infty). Therefore Df=(1,∞).\boxed{D_f=(1,\infty)}. At x=1x=1, the logarithm argument is 00, so it cannot be included.

Example B.10

A square root in the denominator makes the inequality strict

Find the domain of f(x)=1log2(x2−5x+6).f(x)=\frac1{\sqrt{\log_2(x^2-5x+6)}}.

Solution.

If the square root were only in the numerator, its radicand could be zero. Here it is the denominator, so it must be real and nonzero: log2(x2−5x+6)>0.\log_2(x^2-5x+6)>0. Because 2>12>1, the logarithm is increasing. Hence x2−5x+6>20=1.x^2-5x+6>2^0=1. Move 11 to the left: x2−5x+5>0.x^2-5x+5>0. The roots of x2−5x+5=0x^2-5x+5=0 are α=5−52,β=5+52.\alpha=\frac{5-\sqrt5}{2}, \qquad \beta=\frac{5+\sqrt5}{2}. The quadratic opens upward, so it is positive outside the two roots. Thus Df=(−∞,5−52)∪(5+52,∞).\boxed{D_f= \left(-\infty,\frac{5-\sqrt5}{2}\right) \cup \left(\frac{5+\sqrt5}{2},\infty\right).} The endpoints are excluded because they make the denominator 00.

Example B.11

Two nested logarithms

Find the domain of f(x)=ln(ln(4−x2)).f(x)=\ln\bigl(\ln(4-x^2)\bigr).

Solution.

The outer logarithm requires ln(4−x2)>0.\ln(4-x^2)>0. Since ln\ln is increasing and ln1=0\ln1=0, this is equivalent to 4−x2>1.4-x^2>1. Therefore x2<3,x^2<3, which gives −3<x<3.-\sqrt3<x<\sqrt3. At either endpoint the inner logarithm equals 00, which the outer logarithm cannot accept.

Example B.12

Variable base and a quadratic argument

Find the domain of f(x)=logx+1(4−x2).f(x)=\log_{x+1}(4-x^2).

Solution.

Write the three logarithm conditions separately.

The base must be positive: x+1>0⇒x>−1.x+1>0\quad\Longrightarrow\quad x>-1. The base must not equal 11: x+1≠1⇒x≠0.x+1\ne1\quad\Longrightarrow\quad x\ne0. Intersecting all three conditions gives (−1,2)\{0}=(−1,0)∪(0,2).(-1,2)\setminus\{0\} =\boxed{(-1,0)\cup(0,2)}. Each deleted point has a different cause: at −1-1 the base is zero, at 00 the base is one, and at 22 the argument is zero.

Example B.13

A periodic inner function

Find the domain of f(x)=ln(sinx).f(x)=\ln(\sin x).

Solution.

The logarithm requires sinx>0.\sin x>0. On one period, sine is positive for 0<x<π.0<x<\pi. The sine pattern repeats every 2π2\pi, so all admissible intervals are 2kπ<x<(2k+1)π,k∈ℤ.2k\pi<x<(2k+1)\pi, \qquad k\in\mathbb{Z}. Therefore Df=⋃k∈ℤ(2kπ,(2k+1)π).\boxed{D_f=\bigcup_{k\in\mathbb{Z}} (2k\pi,(2k+1)\pi)}. The endpoints are excluded because sinx=0\sin x=0 there. This is a direct use of the periodicity framework from Section 4.3.

B.6 Range problems: pass through the logarithm carefully

If f(x)=loga(g(x))f(x)=\log_a(g(x)), first find the set of positive values attained by gg. Then apply the monotone logarithm to that set. Whether endpoints remain included depends on whether gg actually attains them.

Example B.14

A quadratic inside ln\ln

Find the range of f(x)=ln(x2+1).f(x)=\ln(x^2+1).

Solution.

For every real xx, x2≥0,x^2\ge0, so x2+1≥1.x^2+1\ge1. Equality occurs at x=0x=0. As |x|→∞\left|x\right|\to\infty, the quantity x2+1→∞x^2+1\to\infty. Therefore x2+1∈[1,∞).x^2+1\in[1,\infty). The function lnt\ln t is increasing, hence ln(x2+1)∈[ln1,∞)=[0,∞).\ln(x^2+1)\in[\ln1,\infty)=[0,\infty). Thus Rf=[0,∞).\boxed{R_f=[0,\infty)}. The lower endpoint 00 is included because f(0)=0f(0)=0.

Example B.15

A bounded positive argument

Find the range of f(x)=ln(4−x2).f(x)=\ln(4-x^2).

Solution.

First, the logarithm requires 4−x2>0⇔−2<x<2.4-x^2>0\quad\Longleftrightarrow\quad -2<x<2. On this domain, 0<4−x2≤4.0<4-x^2\le4. The maximum 44 occurs at x=0x=0. Therefore Rf=(−∞,ln4].\boxed{R_f=(-\infty,\ln4]}.

Example B.18

Example B.20

B.8 Logarithmic differentiation

When a variable appears both in a base and in an exponent, ordinary power and exponential rules do not apply directly. Taking logarithms brings the exponent down, where product and chain rules can reach it.

💡 Logarithmic differentiation algorithm

For a positive function y=F(x)y=F(x):

  1. write lny=lnF(x)\ln y=\ln F(x);

  2. use logarithm laws to expand products, quotients and powers;

  3. differentiate both sides implicitly;

  4. multiply by yy;

  5. replace yy by the original function.

B.12 Real branches and the complex logarithm preview

On the positive real axis, exe^x is one-to-one, so its inverse lnx\ln x is single-valued. In the complex plane, ei(θ+2πk)=eiθ(k∈ℤ),e^{i(\theta+2\pi k)}=e^{i\theta} \qquad(k\in\mathbb{Z}), so a nonzero complex number has infinitely many possible arguments. This gives infinitely many logarithm values logz=ln|z|+i(argz+2πk).\log z=\ln\left|z\right|+i(\arg z+2\pi k). To choose one continuous value, complex analysis removes a ray and chooses a range of angles. That ray is a branch cut. The geometric picture appears in the branch-cut diagram in Lecture 4.

The logic is exactly the one used for inverse trigonometric functions:

  1. identify why the original rule is many-to-one;

  2. restrict or cut the domain so one output has one chosen preimage;

  3. declare the chosen branch;

  4. only then speak of a single-valued inverse.

The real restriction and the complex branch cut are not literally the same construction, but they solve the same inverse-function obstruction.

Example B.33

A logarithmic inequality with a quadratic argument

Solve log2(x2−5x+6)≤1.\log_2(x^2-5x+6)\le1.

Solution.

The logarithm argument must be positive: x2−5x+6>0,x^2-5x+6>0, (x−2)(x−3)>0.(x-2)(x-3)>0. Thus x<2orx>3.x<2\quad\text{or}\quad x>3. Because base 22 is greater than 11, the logarithm is increasing: log2(x2−5x+6)≤1⇔x2−5x+6≤2.\log_2(x^2-5x+6)\le1 \Longleftrightarrow x^2-5x+6\le2. Therefore x2−5x+4≤0,x^2-5x+4\le0, (x−1)(x−4)≤0,(x-1)(x-4)\le0, so 1≤x≤4.1\le x\le4. Intersect with the positivity domain: [1,4]∩((−∞,2)∪(3,∞))=[1,2)∪(3,4].[1,4]\cap\bigl(( -\infty,2)\cup(3,\infty)\bigr) =[1,2)\cup(3,4]. Hence x∈[1,2)∪(3,4].\boxed{x\in[1,2)\cup(3,4]}. The points 22 and 33 are excluded because they make the logarithm argument zero.

Example B.34

A range with two vertical asymptotes

Find the range of f(x)=ln(1+x1−x).f(x)=\ln\left(\frac{1+x}{1-x}\right).

Solution.

The argument must be positive: 1+x1−x>0.\frac{1+x}{1-x}>0. The critical points are −1-1 and 11. A sign chart gives −1<x<1.-1<x<1. Differentiate on this domain: f′(x)=11+x+11−x=21−x2>0.f'(x)=\frac1{1+x}+\frac1{1-x} =\frac{2}{1-x^2}>0. Thus ff is strictly increasing. At the endpoints, limx→−1+1+x1−x=0+,limx→1−1+x1−x=+∞.\lim_{x\to-1^+}\frac{1+x}{1-x}=0^+, \qquad \lim_{x\to1^-}\frac{1+x}{1-x}=+\infty. Therefore limx→−1+f(x)=−∞,limx→1−f(x)=+∞.\lim_{x\to-1^+}f(x)=-\infty, \qquad \lim_{x\to1^-}f(x)=+\infty. By continuity and strict increase, every real output occurs exactly once: Rf=ℝ.\boxed{R_f=\mathbb{R}}.

Example B.35

Logarithmic differentiation with a quotient of powers

For x>1x>1, differentiate y=x3x−1(x+1)2.y=\frac{x^3\sqrt{x-1}}{(x+1)^2}.

Solution.

The stated domain makes every factor positive. Take natural logarithms: lny=3lnx+12ln(x−1)−2ln(x+1).\ln y=3\ln x+\frac12\ln(x-1)-2\ln(x+1). Differentiate: y′y=3x+12(x−1)−2x+1.\frac{y'}y =\frac3x+\frac1{2(x-1)}-\frac2{x+1}. Multiply by yy: y′=x3x−1(x+1)2(3x+12(x−1)−2x+1).\boxed{ y'=\frac{x^3\sqrt{x-1}}{(x+1)^2} \left(\frac3x+\frac1{2(x-1)}-\frac2{x+1}\right).} This factored form is usually more useful than expanding into one large rational expression.

§ Appendix B summary

  • axa^x and logax\log_ax are inverse functions; their domain and range are exchanged and their graphs reflect in y=xy=x.

  • If a>1a>1, logax\log_ax is increasing; if 0<a<10<a<1, it is decreasing. This decides whether a logarithmic inequality preserves or reverses order.

  • A logarithm requires positive arguments, positive bases and bases not equal to 11. Denominators, radicals and outer logarithms add restrictions.

  • For a range, first find the positive values of the inner expression, then pass that interval through the monotone logarithm.

  • The area definition lnx=∫1xdt/t\ln x=\int_1^x\,\mathrm{d}t/t gives both the product law and (lnx)′=1/x(\ln x)'=1/x.

  • Logarithmic differentiation is the natural tool when a variable occurs in an exponent or a product of many powers.

  • Branch choices for inverse trigonometric functions and branch cuts for complex logarithms express the same broad principle: a many-to-one rule must be made single-valued before it has an inverse.
