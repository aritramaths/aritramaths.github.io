A. Number Systems and Basic Definitions

For Problems 1–6, decide whether the statement is true or false.

☠ Problem 1

Every rational number is also irrational.

Show solutionHide solution to problem 1

By definition, a rational number is a real number that can be written in the form pq,p,q∈ℤ,q≠0.\frac{p}{q},\qquad p,q\in\mathbb{Z},\quad q\ne0. An irrational number is a real number which cannot be written in this form. Therefore no real number can be both rational and irrational; in set notation, ℚ∩(ℝ\ℚ)=⌀.\mathbb{Q}\cap(\mathbb{R}\setminus\mathbb{Q})=\varnothing. Consequently the assertion that every rational number is irrational is false.

☠ Problem 2

Every integer is also irrational.

Show solutionHide solution to problem 2

Let nn be an arbitrary integer. Since 11 is a nonzero integer, we can write n=n1.n=\frac{n}{1}. This is a quotient of two integers with nonzero denominator, so nn is rational. Thus every integer is rational, not irrational. The given statement is therefore false.

☠ Problem 3

Every irrational number is a real number.

Show solutionHide solution to problem 3

The word irrational is defined only within the real numbers: ℝ\ℚ={x∈ℝ:x∉ℚ}.\mathbb{R}\setminus\mathbb{Q} =\{x\in\mathbb{R}:x\notin\mathbb{Q}\}. Hence every irrational number already belongs to ℝ\mathbb{R}. The statement is true.

☠ Problem 4

Show solutionHide solution to problem 4

At the beginning of the lecture we fixed the convention ℕ={1,2,3,…}.\mathbb{N}=\{1,2,3,\ldots\}. The first element displayed is 11, and 00 is not included. Therefore 0∉ℕ0\notin\mathbb{N}, so the statement is false. This conclusion depends on our declared convention; some books use a different convention.

☠ Problem 5

The sum of two natural numbers is rational.

Show solutionHide solution to problem 5

Let m,n∈ℕm,n\in\mathbb{N}. The natural numbers are closed under addition, so m+n∈ℕ.m+n\in\mathbb{N}. In particular, m+nm+n is an integer. Every integer is rational because m+n=m+n1,m+n=\frac{m+n}{1}, where the numerator and denominator are integers and the denominator is nonzero. Hence the sum is rational, and the statement is true.

☠ Problem 6

Every positive integer is a natural number.

Show solutionHide solution to problem 6

The positive integers are 1,2,3,….1,2,3,\ldots. With our convention this is exactly the set ℕ\mathbb{N}. Therefore every positive integer is a natural number, and the statement is true.

☠ Problem 10
